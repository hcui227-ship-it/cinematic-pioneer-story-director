# 功能菜谱（Feature Cookbook）：每个功能一张最小示例卡

> 本文件按功能逐项给出**可直接复制的最小示例**，覆盖 Skill 的全部能力，方便"我想用某个功能 → 抄这一段"。
> 想看一个镜头从头到尾的完整流程，读 [`director-examples.md`](director-examples.md)；想直接填空，用 [`../templates/`](../templates/)。
> 主线案例是"直播公众审判"短片《全面审批》（演示用），关键方法均附通用例。每张卡标注机制依据文件。

## 目录

- A 导演与叙事
- B 镜头生成引擎（核心）
- C 开场对齐与创作模式
- D 摄影 / 灯光 / 色彩 / 表演 / 声音 / 动作 / 打斗 / PBR 材质工艺
- E 连续性与一致性
- F AI 平台落地与声音
- G 成本、质量与复盘
- H 静帧与其他载体

# A 导演与叙事

### A1 导演意图卡（先解读，再分镜）
**何时用**：拿到剧本/梗概，决定机位之前。内部规划，默认不展示。
```
一句话主题：___（无充分依据标"创作假设"，不冒称作者本意）
本场表层事件 / 戏剧问题：___
角色当下：外在目标 → 障碍 → 策略 → 代价；（可能的）内在需求
人物关系/权力：开始___ → 变化___ → 结束___
潜台词：他说的是___，真正想要的是___
观众信息差：观众比角色 多知道/少知道/同样知道 ___
情绪：起点___ → 触发___ → 转折___ → 终点___；是否发生不可逆改变
贯穿母题（视觉/声音）及其演变：___
```
**例**：12号说"我就是想让她难受"——表层是投票理由，潜台词是她拒绝继续伪装道德优越感；权力从"她被审视"反转为"她主动掌控话语权"。
**依据**：`story-and-performance.md` 第2节。

### A2 既有剧本忠实分镜 vs 梗概原创
**何时用**：判断能不能改台词/补对白。
- 已有剧本：台词、说话者、结局**逐字保留**，不标"可修改"；只做提炼与分镜。
- 一句话梗概且被允许原创：才补足人物行动、冲突、转折和必要对白，避免漫无目的加信息。
- 明确"无对白"：用行为、眼神、声场叙事，不硬塞旁白。
**依据**：`story-and-performance.md` 第1节、`crew-and-performance.md` 第4节。

### A3 Scene→Beat→Shot→Micro-beat 拆解与估时
**何时用**：把一场戏拆成可生成的镜头并估时长。
```
Scene 场景：连续戏剧行动的单位
  └ Beat：令人物/事件/观众认知发生变化的最小单元（先列不可缺的事件，按因果排序）
      └ Shot：成片中一次连续画面（一个 Beat 可跨多 Shot，反之亦然）
          └ Micro-beat：镜内 预备→推进→接触→反应→停顿 的可观察细节
```
估时不平均切秒：动作按"预备重心→轨迹→接触→反馈→收势"，对白按"自然朗读+有意义停顿+听者反应"，信息镜按"线索出现→观众辨认→人物反应"。给**时长范围**，不写死秒数。
**反发呆判据**：主事件完成后若没有新行动/表演/线索/声画预期/有意义留白，就在完成点切走。克制的凝视可以是主动选择，但要写清"谁在等什么、观众得到什么新信息"。
**依据**：`sound-timing-editing.md` 8A。

### A4 反套路创新与形式圣经
**何时用**：重要段落怕拍成模板，或要统一全片风格。
- 识别套路后先问"它的**叙事功能**是什么"，再用结构上不同的机制替代（时间、空间、动作策略、声音、信息揭示、跨领域转译），而不是换色调/加粒子。
- 全片建"形式圣经"：主题问题、核心视听母题、风格基准状态、哪些转折允许规则改变、结尾是否回应开头。创新集中在关键段落，过场以清楚为先。
**例**：不靠慢动作+震镜表现高潮，而让全场唯一一盏顶灯在 12 号开口时不变、周围人群却全部安静——用"声音缺席"而非视觉特效做支点。
**依据**：`innovation-engine.md`、`film-output-checklist.md` 10A。

# B 镜头生成引擎（核心）

### B1 Control Analysis：先问"这镜最难控制什么"
**何时用**：每个要生成的镜头，写词之前。
```
勾选最重难题（可多选，圈一个最重）：
□ identity 身份（脸/人漂）   □ composition 构图机位   □ performance 表演/口型
□ camera 运镜（乱晃/轨迹错） □ spatial 空间/多人站位  □ transition 衔接（重演/相位断/越轴）
□ transformation 形变/特效
```
**例**：制作人边走边回头+镜头绕 180° → 最重是 camera 与 identity 同时 HIGH，预判会抢控制预算。
**依据**：`generation-engine.md` 第3节。

### B2 Control Map：必须控制 / 允许漂移
**何时用**：B1 之后，决定哪些不能漂、哪些放手。
```
SHOT: SH-039
MUST CONTROL：12号身份 HIGH / 正脸口型 HIGH / 固定机位 HIGH / 顶光环境 MED / 胸牌 MED
CAN DRIFT：背景观察员动作与数量、座椅纹理、衣物褶皱、灰尘
```
要点：HIGH 项必须有确定性信号兜底，不能只靠 Prompt；CAN DRIFT 写出来是为了**阻止自己为不可见细节烧重生**。
**依据**：`generation-engine.md` 第4节。

### B3 Control Budget：四因子定级 L0–L3
**何时用**：决定这个镜头最多值得上多少信号。
```
四问：叙事重要度？身份敏感度？运动复杂度？衔接敏感度？
L0 仅Prompt（空镜过场）｜L1 +1参考（单人远景轻运动）
L2 多参考+受控首帧（主角戏/正脸口型/相邻对话）
L3 全套参考+首尾帧+运动空间代理+迭代修复（高潮/复杂运镜/严格接点/多人blocking/奇观形变）
```
**例**：2 秒夜高架车流 = L0，T2V 一条过；主角正脸核心台词 = L2/L3。**预算封顶**：L0 不许为追求完美升到 L3，超预算说明镜头设计不经济，回 Cut Map。
**依据**：`generation-engine.md` 第5节。

### B4 控制信号选择（难题 → 信号）
**何时用**：为每个 HIGH 项找确定性信号。
```
身份/脸   → 角色参考图、多图、首帧
服装造型  → 服装参考（只让 Prompt 写"淋湿/破损"等变化状态）
空间美术  → 场景参考静帧
景别机位  → 构图静帧 / 首帧
精确轨迹  → 运动/空间代理、相机路径、视频参考
末态接点  → 尾帧 / 上一镜成片尾帧
动作规律  → Motion Reference / 代理
姿态深度  → Pose / Depth / Edge / Normal
口型节奏  → 音频 / 台词内嵌
只改一处  → Mask / 局部重绘
氛围/光感/质感/微妙情绪 → 这些才留给 Prompt（或风格参考）
```
**依据**：`generation-engine.md` 第2、6节。

### B5 运动 / 空间代理（Proxy-driven）
**何时用**：精确运镜、多人走位、空间关系用文字锁不住时。
任何能提供"**时间+空间+运动**"的低质量源都是代理，不要精细 3D：Blender 白膜、Unreal 简模、3D 相机路径、AI 粗视频、真人手机实拍、火柴人、pose 序列、depth/blocking 草图。
**例**：要绕制作人 180°，用手机对着一把椅子绕半圈拍一条粗糙视频当代理，喂给代理驱动 I2V；代理只进控制端，不进最终画面。方法论只认"代理"抽象，不绑定软件。
**依据**：`generation-engine.md` 第7节。

### B6 Generation Router：信号组合 → 生成方法
**何时用**：信号选好后落到具体生成路径。
```
T2V ............ L0 探索/空镜
I2V 首帧 ....... 保脸保景保构图（主力）
首尾帧/续写 .... 运动方向、动作接点、锁末态
多图参考 ....... 多主体一致
合成首帧→I2V ... 角色 P 进正确场景，复杂同框
V2V ............ 借已有运动/节奏/表演，或风格化
代理驱动 I2V ... 精确运镜、走位、blocking
结构控制 ....... Pose/Depth/Edge 控姿态深度轮廓
音频驱动 ....... 口型与节奏
Mask 局部修复 .. 只修脸/手/背景，不全片重生
Chain 链式拆分 . 单一方法扛不住的高难题（见 B10）
声画分轨 ....... 规避内嵌口型风险
纯后期 ......... UI/数字/招牌/字幕
```
口诀：**身份优先 I2V/多图；轨迹优先代理/V2V；接点优先首尾帧；局部问题优先 Mask；文字归后期。**
**依据**：`generation-engine.md` 第8节。

### B7 把控制从 Prompt 拿出去（减负前后对比）
**何时用**：每次写 Prompt 前自检。
- 反面（500 字全包）：`一个35岁短发瘦男人，深灰衬衫，坐在黑色椅子，演播厅冷蓝光，镜头缓慢绕他180度，他先低头再抬头说……（再五百字长相陈设轨迹）`
- 正面（身份给参考图、轨迹给代理后）：`他低头停顿一拍，缓慢抬头直视前方，眼神疲惫但不躲闪；冷蓝顶光在颧骨留一道窄高光，背景虚成安静色块；运动跟随代理轨迹，自然克制。`
**依据**：`generation-engine.md` 第6、11节。

### B8 Generation Recipe（存配方而非存提示词）
**何时用**：每镜定稿，供复现/学习/披露。空白表见 `../templates/04-generation-recipe.yaml`。
```yaml
shot: SH-039
control_budget: L3
lip_sync: A+
inputs: { character_ref: CHAR-07_v2, start_frame: SH039_start_v03, end_frame: SH039_end_v01 }
control_signals_used: [multi_character_ref, environment_ref, start_frame, end_frame, embedded_audio]
prompt: { performance: "缓慢抬头，平静疲惫，说完抿嘴不笑", dialogue: "【12号】（平静·很慢·很轻）我就是想让她难受。" }
model: { engine: 实测填, seed: 记录 }
result: { selected_take: v05 }
failure_history: { v01: D1身份漂移, v02: D3吞字, v03: D4自己推镜 }
```
**依据**：`generation-engine.md` 第9节。

### B9 Director Review：Accept / Repair / Reroute
**何时用**：每条生成结果出来，对照 MUST CONTROL 验收。
- **Accept**：不可失败项全过 → 标 accepted/candidate，进粗剪。
- **Repair**：只是脸/手/背景某处坏 → Mask 局部修或短 V2V，**不为局部重生整条**。胸牌数字老不稳 → 转后期。
- **Reroute**：系统级失败，禁止再堆 Prompt。先判**信号缺失 / 信号冲突 / 模型上限**，再换信号、换方法或拆链。
**依据**：`generation-engine.md` 第10节。

### B10 拆控制链（Chain）
**何时用**：身份与复杂运镜/形变在同一段互相打架，代理+V2V 仍保不住。
```
身份 + 180°运镜冲突：
  ① I2V：角色参考 + 固定/轻微横移，先得到"走两步回头"的稳定人物
  ② V2V/代理：叠加绕轨运动（运动交给代理）
  ③ Mask：只对脸部做局部修复
表演/口型失败：降口型级 → 侧脸/反应镜(B级) → 音频驱动或声画分轨
空间/多人混乱：先空间代理锁 blocking，或拆成关系清晰的双人/单人镜
形变/特效失败：首尾帧+结构控制，或分层合成
```
累计到熔断仍不经济 → 回 Cut Map 改镜头设计（并镜/换景别/剪辑规避），这是正当决策不是失败。
**依据**：`generation-engine.md` 第10节。

### B11 反模式：500 字 Prompt 综合症
**何时用**：发现自己在不停加形容词时立刻停。
身份错加长相词、运镜错加轨迹词、动作/构图/空间错都继续加词 → Prompt 臃肿且互相干扰。正确反应是先问"**这条控制该不该从 Prompt 拿出去、交给哪个信号**"。Prompt 越长，常说明控制策略越错。
**依据**：`generation-engine.md` 第11节。

# C 开场对齐与创作模式

### C0 开场对齐：回显 + 列路线 + 白话反问
**何时用**：用户只给一句想法/一张图/一种"感觉"，或明显不熟术语时；S0 第一件事，别直接写分镜。
```text
【回显】你想做一支关于___（题材/主角/设定）的___（成片/分镜/提示词方案），
发在___（平台/画幅），约___秒。
· 你给的事实：___
· 我先替你假设（可改）：竖屏/30–60秒/允许补对白/图生视频+台词内嵌/写实电影感

【接下来我会】
1) 先和你确认下面 3 点（需要你拍板）
2) 做 1 条最便宜的探针，验证___这个最容易翻车的效果（我来做）
3) 出主角定妆和___个场景图（有参考图请发我）
4) 列镜头蓝图给你确认 → 逐镜生成 → 攒一批先粗剪

【只问 3 个，其余我用默认】
1) 竖屏还是横屏？（推荐竖屏，适合手机端）
2) 结局要___还是___？（推荐___，因为___）
3) 用哪个 AI 视频工具、能不能参考图+说话配音？（没有就按通用图生视频规划）

【先打个预防针】___效果目前单条通常做不稳，我会先探针；
不行就___（拆镜/侧脸/画外音/后期），不影响成片。
```
**要点**：只问"答案不同会方向性返工"的问题，一次 ≤3–5 个、给推荐默认；用户说"你看着办"就走省心默认档（solo-workflow 0.4）；对用户只谈效果不谈术语（不问 L 几/要不要 PBR，问"脸和动作是否必须一模一样""要游戏 CG 质感还是纪实真实感"）。

### C1 可跳转状态机与素材先行
**何时用**：不同起始素材决定从哪进。
```
S0 上锁 → S1 探针 → S2 故事/Beat → S3 Cut Map → S4 契约+Control Map
       → S5 路由+Recipe → S6 生成+评审 → S7 粗剪 → S8 精剪/QC/交付
可任意跳转：
  素材先行：S0→S1→S6→S7→S2（先有画面再倒推故事）
  边剪边生：S7↔S4↔S6 循环
素材推翻规划时，以素材为准回改 Cut Map，不维护已不成立的纸面分镜。
```
**依据**：`solo-workflow.md` 第1节。

### C2 Hard / Soft / Open 三类锁
**何时用**：S0 必做，标注每个决策能动哪类锁。
```
Hard（不可自行改，要改找发起人）：既定台词/结局/事实、禁令、安全红线、已锁主角身份
Soft（可被证据推翻，但要记录）：镜头数、时长、景别、运镜、场次、批次、候选模型
Open（鼓励探索）：开场、转场、VFX 细节、实验镜、节奏声音
```
探索期别把 Open/Soft 当 Hard 锁死，否则会为一个本可放弃的镜头反复烧积分。
**依据**：`solo-workflow.md` 第2节。

### C3 Probe 风险探针
**何时用**：完整规划前，验 1–3 个"做不出来全片垮"的点。
```
假设：多人重叠抢话 + 温柔零情绪系统女声画外切入，平台没验证过
最便宜验证：1 条 3 秒、两人抢话+系统声插入
结论三选一：能做 / 改设计 / 换路线或删戏
本例结论：单人口型可用，两人精确重叠不稳 → 重叠拆两人各一镜再剪，系统声走画外(C级)
```
每个 Probe 只验一个假设、可丢弃；通过前不展开全片契约。
**依据**：`solo-workflow.md` 第3节。

### C4 Cut Map：必须镜 vs Candidate
**何时用**：S3，先有粗剪蓝图再逐镜展开。
```
SH-039 12号真话固定长镜 | 必须 | A+ | L3 | 合成首帧I2V+尾帧
SH-040 众人回避目光群像   | Candidate | B | L1 | I2V侧脸
SH-041 大屏计票跳动       | 必须 | C | L0 | T2V，数字纯后期
```
Candidate 的去留交给粗剪；此阶段不写摄影灯光完整提示词。空白表见 `../templates/02-cut-map.md`。
**依据**：`solo-workflow.md` 第4节。

### C5 粗剪反推（补 / 删 / 改）
**何时用**：攒到一批能用素材（含 Candidate）就尽早粗剪，哪怕无配音无调色。
```
删：SH-040 反应群像与 SH-039 结尾停顿信息重复 → 删，省整组群演镜头
补：系统声切入后缺"把话咽回去"的特写 → 补 SH-038b（B级侧脸，低成本）
改：SH-039 素材停顿比预估长 1 秒更有力 → 以素材为准顺延，Beat 由素材反推
```
粗剪回答：故事讲清了吗？哪镜多余？哪里缺信息？节奏哪里塌？A+ 表演成立吗？
**依据**：`solo-workflow.md` 第11节。

# D 摄影 / 灯光 / 色彩 / 表演 / 声音 / 动作工艺

> 这些是"被镜头风险触发加载"的工具，不为每镜凑满层数；每个专业词紧跟可见/可听结果。

### D1 运镜要有叙事理由
**何时用**：决定镜头动或不动。
- 反例（无理由）：每镜都缓慢推镜。
- 正例：12 号道德支点长镜 = **固定 locked-off**，让观众无法回避她的脸；信息/情绪需要靠近才推，且写清"推近让观众被迫直视"。情绪重的镜头倾向固定，跟动作才动。
- 要求"不动"也是强控制：写进 Prompt 与尾帧，防模型自己加运镜（D4）。
**依据**：`camera-lighting-color.md` 第5节、`toolbox-cinematography.md` 第1节。

### D2 灯光叙事链
**何时用**：设计光的时候按因果走，不堆光位名词。
```
场景真实光源 → 光照对象与方向/硬软 → 谁被照亮/遮蔽/分离 → 观众看到或暂看不到什么 → 随哪个事件改变
```
**例**：控制室只用监看屏的冷光做来源，制作人追数据时脸被数据墙照亮、技术员老马主动按停时退到屏光外变暗——光随"谁还在推动这场直播"改变。不造无来源聚光灯；侧光≠善恶。
**依据**：`camera-lighting-color.md` 第6节。

### D3 色彩：一级 / 二级 / 跨镜，描述结果不虚构软件
**何时用**：要色彩服务人物关系与心理，且不谎称跑了调色软件。
```
一级（整体）：室内冷灰但人物肤色自然、暗部保留眼神与衣料层次
二级（局部）：仅让大屏红光/关键道具跳出，背景降饱和但纹理可见
跨镜：反打时不突然偏绿或改变脸部亮度；相邻镜色温曝光匹配
```
冷色≠坏人、暖色≠善良；模型做不到像素级二级调色时，用光源、服装配色、构图实现，不承诺。
**依据**：`camera-lighting-color.md` 第7节。

### D4 表演可观察化（不写情绪形容词）
**何时用**：把"强装镇定/愤怒/冷漠"翻译成身体。
- 反例：`她很紧张`。
- 正例：`吸气延迟半拍，目光保持不躲，但拇指无意识摩挲号码牌边缘；开口第一字干涩，随后才平稳；没有攥拳、流泪或颤抖。`
- 顺序：想让对方做什么 → 采取什么策略 → 哪个刺激让策略失败 → 身体/声音显露什么 → 对方如何反应。允许无动作、背影、沉默。不制造统一微表情配方。
**依据**：`crew-and-performance.md` 第4节。

### D5 声音设计 / J-cut / L-cut / 静默
**何时用**：声音是分镜正文，不是后期附录。
```
环境底噪：演播厅低频电流+人群呼吸般的嗡鸣，标注声源与强弱
J-cut 声音先行：下一场系统女声在上一镜尾部提前进入，制造期待
L-cut 声音延续：12号台词延续到众人回避目光的反应镜
静默：她说出核心句后环境声被主观压低，只剩一声 TALLY 电流轻响
音乐：不为煽情自动铺 BGM；音乐用于反讽/对比/推进或不用
```
模型音频能力未验证时，分镜保留声音意图，执行可分轨；不承诺精准时间码。
**依据**：`sound-timing-editing.md` 第8节。

### D6 多机位职能 / 事件切点 / 动作相位
**何时用**：一场戏需要多个角度，或跨镜接动作。
- 机位是**职能不是 A/B/C/D 配额**：空间主机位（讲清位置）、关系机位、表演/反应机位、细节插入、主观/过肩；能在稳定全景讲清就不硬切特写。
- 切点落在真实事件：动作切（起手/运动中切，下镜同相位继续，不重新起手）、视线匹配、反应切、细节插入、保持不切。
- 锁 180° 轴线与屏幕方向；多机位覆盖供剪辑选择，但**成片时间线上同一动作只发生一次**。
**依据**：`sound-timing-editing.md` 8A-B-C。

### D7 动作专项与复杂度分级 / 拆镜
**何时用**：打斗、追逐、走位、复合 VFX。
- 动作链：起始站位距离 → 预备发力 → 轨迹 → 命中/闪避 → 受力位移 → 收势/下一招；起手姿势继承上一事件末态。
- 复杂度：保守（单镜单主事件、稳定景别、少交互）／标准／复杂（多人物+复合VFX+长调度，仅有成功记录或分段方案才用）。
- 单段同时要"复杂多人交互+准确口型+复杂运镜+复合VFX"=超载（D8）→ 拆 Shot，降同时任务数。群像拆成关系清晰的双人/单人镜。
**依据**：`production-continuity.md` 第10节、`toolbox-cinematography.md` 5A。

### D8 打斗 / 动作：运动代理 + 多机位链式 + 力度六要素
**何时用**：冷兵器、拳脚、追逐、群战等 C 类动作（完整端到端走查看 `director-examples.md` 示例 7）。
- 动作戏 **identity 降级、运动/空间/形变升 HIGH**；主力信号是**运动/空间代理**（白膜、火柴人、手机找人走位拍的粗演视频），用它锁走位、兵器轨迹与相机后坐——不靠 Prompt 描述动作编排。
- **多机位分别生成、按动作相位剪辑**：固定宽景主机位跑完整大动作；接触点单独出侧向/贴地仰拍插入镜；受力与反应出中景；从不让模型在一段里切机位，**同一招在成片只发生一次**。
- 接触形变不到位用 V2V / Mask 局部加强，不重生整条；单段超载就再拆成更短的"将触 / 咬合 / 分开"。
- **力度六要素逐条自检**：①蓄力慢→爆发快→收势缓冲（非匀速）；②力度由核心躯干→肩→臂→手/武器逐级传导、扭腰送肩甩臂有时滞；③受击形变（甲片内凹、布料挤压、肌肉面部甩动、非刚体二次晃动）；④冲击连锁（火星→台面粉尘裂纹→远处挂布延迟掀起）；⑤动量连续（重心、披风发丝、镜头共享同一速度矢量，急停有前冲惯性）；⑥镜头受击反馈（沿受力方向后坐 + 命中顿帧：画面极短一凝、碎屑悬在半空随后猛然炸开，再阻尼回正），不无差别叠加震镜慢放。
- 写实无附魔：金属碰金属可有少量火花，**布料/人体接触不产金属火花**；不要火球、光刃、全程子弹时间、软绵绵匀速。
- 数字只进说明区，成品用视觉锚点："顿帧 0.1–0.2s"写成"命中瞬间画面极短一凝、碎屑悬停随后炸开"。
**依据**：`toolbox-rendering-3a.md` 第 4/5/7/8 节、`toolbox-cinematography.md` 第 3/5A 节、`director-examples.md` 示例 7。

### D9 PBR / 3A 材质：静帧锁定，视频只写状态变化
**何时用**：3A/概念质感、写实皮肤、金属武器甲胄、织物皮革、奇幻能量材质；定妆照与道具图同样适用。
- 核心原则：**材质在定妆/道具静帧阶段用参考图锁死，视频 Prompt 只写受力、磨损、沾尘、沾汗这类"状态变化"**，不堆"8K / 高精金属 / 极致质感"空词去赌模型。
- 渲染基底：PBR 物理材质、GI 全局光照、AO 环境光遮蔽、接触阴影、光线追踪反射/折射、SSR 屏幕空间反射。
- 皮肤：SSS 次表面散射（耳/鼻/指缝透光）、毛孔细纹、绒毛汗毛、皮脂高光、皮下静脉、瑕疵不对称；**禁磨皮塑料感、蜡像脸**。
- 金属：法线贴图微凹凸、各向异性拉丝反光、清漆层、锈蚀氧化、磕碰露底、指纹油污；**刃口高光窄而锐利，钝器反光散**。
- 织物/皮革：经纬织纹、缝线毛边、褶皱受力方向、汗渍水渍、做旧褪色；皮革摔纹、油边、折痕压痕、握持处包浆。
- 石木陶 / 能量：石材颗粒层理、木材年轮劈裂、陶器开片；自发光菲涅尔边缘光、体积内透、符文流动、半透明晶体内絮。
- 统一规则：同画面反光逻辑一致（金属高光比石材更锐、暗部仍有反射），磨损位置符合握持处/关节/刃口/鞋底；光比主:辅≈3:1–8:1（夜景/戏剧），COS 棚拍 2:1–3:1。
- 细节按景别取用：特写取毛孔/微划痕/针脚/眼神光，中景取服装大褶皱/主材质感/武器轮廓光，远景取宏观光影/体积雾/轮廓剪影/大气透视，不全量堆砌。
- 英文正向（国际模型）：3A `AAA game graphics, Unreal Engine 5, photoreal PBR materials, ray tracing, global illumination`；写实 `photorealistic, shot on 35mm, subsurface scattering, rim light, volumetric light, HDR`；负面 `plastic skin, wax face, extra limbs, fused fingers, malformed hands, text, watermark`。
**依据**：`toolbox-rendering-3a.md` 第 1–3 节、`toolbox-glossaries.md` 第 2/9/10 节、`toolbox-photorealism.md`。

# E 连续性与一致性

### E1 全片状态账本与末态继承
**何时用**：防止切镜后人物重置、左右反转、道具跳变。
内部维护：角色外观衣装道具归属、画面左右/前后层、面向与视线、走位、道具伤痕变化、地标、光源天气、谁已知什么、台词说过没、画内声源、镜头侧与末态。**下一镜从上一镜实际末态及同一动作完成相位继承，不每镜把人摆回起点。**
**例**：小乔起身说"我负责"后走向台前，下一镜她必须已在台前行进中，不能又坐回主持位。
**依据**：`production-continuity.md` 第10节。

### E2 尾帧当首帧 + 分批保脸
**何时用**：跨镜连续、同角色多镜。
- 优先用上一镜**实际尾帧**（或附近截帧）当下一镜首帧，锁动作相位、服装污渍、道具状态；拿不到尾帧就在下一镜开头**显式复述末态**（谁在哪、什么姿势、手里什么、光从哪来）。
- 同一角色的所有镜头集中一批连续生成、复用同一定妆照当首帧，脸最稳；剪辑顺序≠生成顺序（见 F7）。
**依据**：`ai-video-platform-production.md` 第2、6节。

# F AI 平台落地与声音

### F1 平台五维能力判定
**何时用**：开工/首次用某平台，先实测再定生产路径。
```
□ 图生首帧：能否传参考图/首帧？能否同时给角色+场景多图？
□ 尾帧/首尾帧：是否支持尾帧锁定、首尾续写？
□ 时长：单段秒数、能否续写？（决定 Shot 是否拆段）
□ 台词/音频/口型：是否台词内嵌带配音？口型质量？支持多人抢话吗？
□ 运镜/语言：对中文运镜词、焦段词识别度？是否爱乱加运镜？
```
首次用或能力未知，先拿 1–2 个有代表性的难镜（一个带台词正脸、一个动作衔接）做最小测试再批量。具体积分/时长/参数以当期实测为准，不写死。
**依据**：`ai-video-platform-production.md` 第1节。

### F2 参考图物料体系
**何时用**：开视频前先备齐资产（图像比视频便宜得多）。
```
角色定妆照：每个有台词/近景角色一张，统一半身3:4、统一光向，固定年龄发型服装肤色标志物
场景 establishing 图：每个主要场景一张大全景/空景，固定布局、光源方向、色温、地标
关键道具图：推动剧情的装置/按钮/对讲机
配角/群演无定妆：标"现场生成"，第一次跑出合适脸就存帧当后续参考
```
**依据**：`ai-video-platform-production.md` 第2节。

### F3 首帧组合规则
**何时用**：决定每个镜头拿什么当首帧。
```
单人近景      → 角色定妆照当首帧，场景靠提示词带
单人在特定场景 → 角色图+场景图（多图）；只支持单图则先图生图把人合成进场景再当首帧
多人对话      → 主说话者定妆照当首帧，或先出"多人同框构图图"，避免模型自由排位置
场景空镜/群像 → 场景 establishing 图当首帧
```
**依据**：`ai-video-platform-production.md` 第2节。

### F4 台词内嵌 vs 声画分轨（决策树）
**何时用**：成本有限、不想单独做配音时。
```
1 平台支持台词内嵌带配音、且测试片口型可用 → 内嵌（省一次分轨）
2 口型不可用但能生成画面 → 人物按台词节奏做说话动作，配音分轨后期对口型；
  或正脸台词镜改侧脸/背影/反应镜规避（B级）
3 平台不支持音频 → 声画彻底分轨，分镜只保留声音意图
4 多人重叠/抢话/精准气口单条不稳 → 该句分轨，或拆两人各一镜分别生成再剪
```
**依据**：`ai-video-platform-production.md` 第4节。

### F5 台词书写规范（语气语速前置 / 标点承担节奏 / 抢话打断重叠）
**何时用**：台词内嵌进视频提示词（画面描述之后），已有台词逐字保留。
```
格式：【角色】（语气·语速·情绪·气息·停顿）台词原文
【12号】（平静·语速很慢·音量很轻·句中停顿一拍）我点反对……不是因为她无辜。（停顿）我就是想让她难受。
标点：—— 被打断/话没说完；…… 迟疑停顿；？ 反问；句号短停、逗号气口（不写"停顿2秒"）
抢话：【17号】（抢话，压过32号）你先别装！
打断：32号台词用 —— 收，紧接 17号
重叠：标（与上句同时，重叠约1秒），并把两人拆到不同镜头分别生成、剪辑叠声
画外：【周启·画外】……（镜头可停在听者脸）
系统/广播：【系统女声·PA】（温柔·零情绪·匀速）检测到违规发言。（不对应任何人物口型）
```
**依据**：`ai-video-platform-production.md` 第4节。

### F6 口型分级 A+/A/B/C（镜头级，不是角色级）
**何时用**：决定积分花在哪些嘴的镜头上。
```
A+ 正脸+核心台词/情绪转折，观众必看嘴：严格lip-sync，多生成几条选最好，宁可此处花积分
A  正脸或3/4脸、有台词非核心：基本同步，1–2条选可用
B  台词可遮挡/弱化：主动用侧脸、背影、前景遮挡、听者反应镜、手部道具插入规避
C  画外系统声/群杂/环境声/枪响/无声：不做口型，群演不给逐人对嘴
```
同一角色不同镜级别可不同；A+ 在清单里标★。
**依据**：`ai-video-platform-production.md` 第5节。

### F7 低成本 BATCH 分批（不按剧情顺序生成）
**何时用**：积分/时间有限。
```
1 先资产后视频（先出齐定妆照+场景图锁视觉）
2 按角色/场景集中分批：同一角色全部镜一批复用定妆照，再换角色；控制室镜一批、群像一批
3 按口型/难度排优先级：A+ 先做多做，A 次之，B 用规避构图，C 最后一条过
4 群像降级：一次只 2–5 个前景有动作的人，其余背景，不要求百人口型
5 蒙太奇/空镜/纯后期最便宜，穿插或放最后
6 每段动作前后留约半秒转场手柄，切点落在真实动作/反应/视线/声音事件
7 终局高潮依赖全片连续性，放最后做（人物脸、场景、道具都已稳定）
建议顺序：主角全部镜→其他主角→对手戏→群像→蒙太奇空镜→闪回→终局→纯后期片尾
```
按 BATCH 列勾选清单（首帧资产/口型级/提示词/是否已过），做完一批勾一批。
**依据**：`ai-video-platform-production.md` 第6节。

### F8 可读中文 / UI 一律后期
**何时用**：屏幕 UI、计票数字、招牌、短信、字幕。
多数模型汉字会乱码：统一写"**内容后期合成，画面只留发光矩形/占位**"，不让模型产可读中文（剧情明确需要乱码除外）。
**例**：大屏观看人数与投票数字 → 画面只生成一块冷色发光矩形和跳动光感，数字后期叠；TALLY 的 "ON AIR" 若模型产不稳也后期。
**依据**：`ai-video-platform-production.md` 第3节、缺陷 D5。

### F9 转场手柄与 G6 出片质检
**何时用**：生成留缓冲、出片逐条核。
- 手柄：动作前后各留约半秒可剪缓冲，不按整数秒切。
- G6 重点查 AI 特有失败：跨镜身份漂移、手指/肢体融合、说话者与口型错位、无理由运镜、中文乱码、人数道具跳变、动作重演、武器/接触穿帮。发现问题表单变量修，不整段重烧。
**依据**：`toolbox-checklist.md` G6、`ai-video-platform-production.md` 第7节。

# G 成本、质量与复盘

### G1 导演 Shot Spec 与平台适配器分离
**何时用**：防换平台/模型升级后整套重写。
- 模型无关母版（摄影/运镜/灯光/色彩/表演/材质/声音 + 首末态/台词/口型级/切点/**可判定验收标准**）保持不变。
- 平台适配器（吃整句还是关键词、负面词格式、时长比例参数、首帧怎么传、内嵌还是分轨）随平台只重写这一薄层。
- 不把平台参数、积分、模型名焊进导演母版。
**依据**：`ai-production-measurement.md` 第1节。

### G2 生成日志与可用秒成本
**何时用**：批量时边做边记（表见模板5）。
```
首轮可用率 = 一次过镜数 ÷ 总镜数
每通过镜重生次数 = 总生成条数 ÷ 通过镜数
缺陷 Pareto = 按 D 编号统计，前 2–3 类往往造成 80% 废镜
可用秒成本 = 总积分(钱) ÷ 最终可用镜头秒数（跨平台/项目唯一可比口径）
```
**依据**：`ai-production-measurement.md` 第2节。

### G3 缺陷 D1–D10 诊断
**何时用**：每条废镜填码、按码取对策（单变量改，别一次改多处）。
`D1身份 D2肢体手指 D3口型台词 D4运镜 D5文字UI D6动作衔接 D7光色跳变 D8单段超载 D9融化拖影 D10道具人数穿帮`，对策见模板5-B 或 `ai-production-measurement.md` 第3节。

### G4 熔断与两次/三次规则
**何时用**：防止同一镜无限烧积分。
```
第1次失败：单变量改 Prompt（不推翻路线）
第2次失败：降负荷/拆镜、降口型级(侧脸反应镜)、降连续性投资、改 must-get 优先级
第3次失败：换 Generation Route(控制方式) 或换模型；仍不行回 Cut Map 改戏
硬阈值：同镜同方案连续 3 条不过即停；A+ 上限 5–6 条；C 级挑能用就过
每次熔断记下"最后怎么解决的"，沉淀对策库
```
**依据**：`solo-workflow.md` 第7节、`ai-production-measurement.md` 第4节。

### G5 镜型→模型路由与回归集
**何时用**：多模型选型，不押万能模型。
挑 5–6 个覆盖主要镜型（静态表演/对白正脸/多人/动作走位/复杂运镜/VFX/空镜）的代表镜，用手头 2–3 个模型各跑一遍，记录谁在哪类过、主缺陷，得到路由表 v1。**回归集长期保留：模型每次大升级先重跑这 5–6 镜，确认脸/风格/口型没漂移再用于正式镜头。**
**依据**：`ai-production-measurement.md` 第5节。

### G6 Asset Bible 版本锁
**何时用**：资产多、跨场次、要改脸/改场景时。
统一命名带版本（`CHAR-01_小乔_v2.jpg`、`SH-007_p3`），改了升版本不覆盖；记来源/授权/关联 Shot；脸中途改要明确"从哪个 Shot 起换新版"，避免半片新脸半片旧脸。表见模板5-C。
**依据**：`ai-production-measurement.md` 第6节。

### G7 个人 Gate 与实验镜配额
**何时用**：一人分饰多角，靠切换视角验收。
```
Gate：意图/分镜锁定 → 资产锁定 → 代表测试镜通过 → 按批生成(日志+熔断) → 终剪声画 → 盲测 → 发布 → 复盘
切换帽子：导演(叙事) → AI TD(模型/参数/成本) → 连续性资产(脸道具) → 剪辑声音(节奏) → QA(按验收标准判过废)
没锁资产不批量；代表镜不过不批量。
保留 10%–20% 实验镜配额，允许偏离标准模板探索，防止全片被安全模板磨平。
```
**依据**：`ai-production-measurement.md` 第7节。

### G8 盲测 / 复盘 / AI 披露
**何时用**：终剪后、发布前/后。
- 盲测：找 2–3 个没看过剧本的人，只问 ①讲了什么 ②谁做了什么、结局如何 ③哪里没看懂/出戏。导演自己清楚≠观众看懂。
- 复盘：用日志回看首轮可用率、重生次数、缺陷 Pareto、可用秒成本、哪类镜最烧钱，对策回填。
- 披露：用 Recipe + 日志 + Asset 台账导出 AI 使用说明（模型名版本、Prompt 版本、首帧资产版本、参考素材授权、AI 参与范围、人工环节）。
**依据**：`ai-production-measurement.md` 第8–9节。

# H 静帧与其他载体

### H1 静帧 / 海报（不进入视频引擎）
**何时用**：只要单张图、角色设定、海报。
不写运镜、时间轴、声音；只取摄影/灯光/表演(姿态)/材质层，重视比例与服装一致；用户没要求就不加环境雾、速度线、多余特效。写实人像参考 `toolbox-photorealism.md`，3A/材质参考 `toolbox-rendering-3a.md`。
**例**：一张 12 号定妆照——`红座椅区，半身3:4，顶光柔和明暗分界，灰发灰外套12号胸牌，自然肤质与布料纹理，平静正视，浅景深背景虚成暖红色块`，不写任何镜头运动。

### H2 只要剧本 / 只要分镜 / 只要平台提示词
- 只要剧本：按剧本格式交付，不硬附分镜表。
- 只要分镜：交全局设定 + Cut Map/分镜，不附整套逐镜提示词。
- 明确要某平台可复制提示词：才走 S4–S5 出 Contract+Control Map+精简 Prompt，并按平台适配器转换；不默认两套重复版。
**依据**：`film-output-checklist.md` 第11节、`solo-workflow.md`。
