# 导演实战示例集（Director + Generation Router）

> 本文件展示 Skill 在真实流程里**实际产出什么**。主线是一部"直播公众审判"题材的 AI 短片（方法论的实战来源，镜头编号与台词均为演示用例）：一档让百名观察员在线审判"网络罪人"的节目，系统逐个反揭观察员自己的旧言论，群体从审判他人滑向互相撕咬，红色 TALLY 灯始终亮着。
> 阅读顺序：示例 1 是一个镜头的**完整端到端走查**；示例 2–5 分别拆开控制预算、Reroute、导演层、声音口型；示例 6 演示如何迁移到任意题材；**示例 7 是动作/打斗专场**——运动空间代理、多机位链式生成、接触点插入镜与 PBR 材质锁定。

---

## 示例 1　一个正脸对白长镜的完整端到端走查

镜头：观察员席 12 号老太太，在众人沉默后，平静说出一句让全场转向的真话。这是全片最重的固定长镜（A+ 口型）。

### ① Shot Contract（S4）

- **镜号 / Beat / 叙事任务**：SH-039 ／ B-群体撕裂的转折点 ／ 拿掉它，观众不会相信"审判者也会被审判"。
- **首态 → 末态**：她低头攥着号码牌 → 缓缓抬头直视镜头（=她在看屏幕里的被审者），说完后嘴角没有胜利者的笑。
- **不可失败项（≤3，提示词最前）**：
  1. 12 号的脸与定妆照一致（灰发、灰外套、12 号胸牌）；
  2. 正脸口型对上整句台词，中间有一次真实的停顿；
  3. 全程固定机位、不推不拉，让观众无法回避她的脸。

### ② Control Analysis（S4）

最重的两个控制维度：**performance（口型 + 微表情）** 与 **identity（主角正脸）**；camera 反而是"必须不动"，spatial 简单（单人红座椅）。

### ③ Control Map（S4）

```
SHOT: SH-039
DIRECTOR INTENT
  情绪弧：回避 → 卸下伪装后的平静
  叙事功能：全片道德支点，她替所有人说出真话
  关键瞬间：抬头直视 + "我就是想让她难受"
MUST CONTROL
  12号身份        HIGH
  正脸口型        HIGH
  固定机位        HIGH（要求"不动"也是一种强控制）
  顶光/红座椅环境 MEDIUM
  胸牌号码        MEDIUM（不稳就后期合成）
CAN DRIFT
  背景其他观察员的动作与数量、座椅纹理、衣物褶皱、灰尘
```

### ④ Control Budget（S4）→ L3

叙事重要度 HIGH（道德支点）＋身份敏感 HIGH（正脸定妆角色）＋运动 LOW（固定）＋衔接 MEDIUM（前后是群体反应镜）。口型 A+ 把整体推到 **L3**，但"运动低"意味着**不需要运动代理**——L3 不等于把所有信号堆满，只上真正 HIGH 的。

### ⑤ 控制信号分配 + Router（S5）

| 控制需求 | 交给的信号 | 不再写进 Prompt 的内容 |
|---|---|---|
| 身份/服装/胸牌 | 角色定妆参考图（多图：正脸+半身） | 不描述长相、不堆服装细节 |
| 红座椅/顶光环境 | 观察员席场景参考图 | 不罗列陈设 |
| 构图/机位/起始姿态 | 由定妆+场景**合成的首帧**（她低头坐定） | 不写机位参数 |
| 抬头动作的终点 | 尾帧（抬头正视、表情平静） | 不描述末态 |
| 口型/气口 | 台词内嵌生成（平台已验证可用） | — |
| 微表情/氛围 | **留给 Prompt** | 这是 Prompt 该干的 |

**路线（Router）**：图生图合成首帧 → **I2V 首帧驱动 + 尾帧约束 + 角色多图参考 + 台词内嵌**。
**不推荐纯 T2V**：同时要求身份一致 + 准确口型 + 特定表情，单靠文字负担过高，脸必漂。

### ⑥ 最小有效 Prompt（S5，把控制拿出去之后）

> 画面已由首帧锁定，Prompt 只剩表演与氛围：
>
> 老人缓慢抬起头，直视前方，眼神平静而疲惫，没有愤怒也没有得意。开口前有一次近乎不可察觉的吸气与停顿，语速很慢、很轻，像说一件早就想清楚的事；说完轻轻抿嘴，不笑。红色座椅区顶灯在她脸上形成柔和的明暗分界，背景人群虚化成安静的色块。固定镜头，自然克制的表演。
> **台词（内嵌）**：【12号】（平静·语速很慢·音量很轻·句中停顿一拍）我点反对……不是因为她无辜。（停顿）我就是想让她难受。
> 负面：不要夸张表情、不要流泪、不要镜头推拉、不要胸牌号码清晰（号码后期合成）。

### ⑦ Generation Recipe（S5，存档）

```yaml

director_intent: { 情绪弧: 回避→平静, 叙事功能: 全片道德支点, 关键瞬间: 抬头直视+核心台词 }
control_budget: L3
lip_sync: A+
control_map:
  must_control: { 身份: HIGH, 正脸口型: HIGH, 固定机位: HIGH, 顶光环境: MEDIUM, 胸牌: MEDIUM }
  can_drift: [背景观察员动作数量, 座椅纹理, 衣物褶皱, 灰尘]
strategy: composite_startframe_then_i2v
inputs:
  character_ref: [CHAR-07_face, CHAR-07_halfbody]
  environment_ref: SET-03_observer_seats
  start_frame: SH039_start_v03   # 低头坐定
  end_frame: SH039_end_v01       # 抬头正视、平静
control_signals_used: [multi_character_ref, environment_ref, start_frame, end_frame, embedded_audio]
continuity: { 承接: SH-038 群体静默尾帧, 末态交接: SH-040 群体反应首帧 }

  performance: "缓慢抬头，平静疲惫，无怒无得意；开口前吸气停顿，慢而轻，说完抿嘴不笑"
  atmosphere: "顶光柔和明暗分界，背景人群虚化为安静色块，固定镜头"
  dialogue: "【12号】（平静·很慢·很轻·停顿一拍）我点反对……不是因为她无辜。（停顿）我就是想让她难受。"
  negative: [夸张表情, 流泪, 推拉镜头, 胸牌号码清晰]

failure_history:
  v01: 身份漂移，脸变年轻(D1)
  v02: 口型对上前半句、后半句吞字(D3)
  v03: 镜头自己缓慢推近(D4)
  v04: 表情过度、像控诉(D-表演)
  v05: 选用
repair_reroute_log:
  - v01→补第二张半身参考、首帧换高清合成版（Repair 级信号增强）
  - v02→台词切两句分别内嵌、停顿显式标注（单变量改词）
  - v03→Prompt 与尾帧都强调"固定/locked-off"，关闭运镜倾向（单变量）
  - v04→删掉"沉重/控诉"类词，只留"平静疲惫"（减负）
```

### ⑧ Director Review（S6）

v05 对照三条不可失败项逐项判：身份一致 ✓／口型与停顿成立 ✓／全程固定 ✓ → **Accept**，进粗剪。胸牌号码在所有 take 里都不稳，按预案**转纯后期**（UI/文字层），不为数字重生。

## 示例 2　控制预算对比：L0 / L2 / L3 三个镜头

| | **L0 过场空镜** | **L2 正脸对白** | **L3 高潮长镜** |
|---|---|---|---|
| 镜头 | SH-010 演播厅大全景，计票数字在大屏跳动 | SH-021 周启抬头看屏幕，一句短句 | SH-059 主持人小乔起身说"我负责" |
| 叙事重要度 | LOW（建立空间） | MEDIUM | HIGH（主角抉择） |
| 身份敏感 | 无（远景人群） | HIGH（主角正脸） | HIGH（主角正脸+全身） |
| 运动复杂 | LOW | LOW（微抬头） | MEDIUM（起身+向前一步） |
| 衔接敏感 | LOW | MEDIUM | HIGH（接制作人倒下） |
| **信号配置** | 仅 Prompt | 角色参考 + 受控首帧 + 内嵌台词 | 角色+场景参考 + 首帧 + 尾帧 + 一个简单起身代理 |
| 路线 | T2V，大屏数字**纯后期** | I2V 首帧 | 代理引导 I2V + 尾帧 |
| Prompt 长度 | 1–2 句 | 3–4 句 | 可展开表演/光色多层 |
| 失败策略 | 挑能用就过，不重生 | 同方案≤3 条，否则降侧脸/反应镜 | 上限 5–6 条，仍不行回 Cut Map 改拍法 |
| 口型级 | C（无对白，仅系统画外声） | A | A+ |

要点：**L0 的大屏数字、L2/L3 胸牌与计票 UI 全部转后期**，从不让模型生成可读中文。

## 示例 3　Reroute 拆链：身份与运镜互相打架

需求：控制室里制作人沿导播台快步走过、回头看大屏，镜头要绕他做约 180° 环绕；他是定妆角色，脸不能漂。

- **失败现象**：用"角色参考 + 一段长 Prompt（详细描述绕轨轨迹）"连续生成 3 条，要么脸漂、要么轨迹只转了 60°、要么他像在原地滑行。
- **诊断（Control Analysis）**：这是 **identity(HIGH) 与 camera(HIGH) 在同一段里抢模型的控制预算**，属于信号冲突，不是词不够。第 4 次改 Prompt 被禁止。
- **Reroute：拆成控制链（Chain）**：
  1. **先保人**：角色参考 + 简单固定/轻微横移，生成"他走两步回头"的稳定镜头（I2V）；
  2. **再加运镜**：用一条粗制**运动代理**（手机拍椅子绕半圈 / 简模相机路径）做 V2V 或代理驱动，把 180° 环绕叠加上去，运动由代理负责；
  3. **最后修脸**：环绕后脸若变形，用 Mask 只对脸部做局部修复，**不重生整条**。
- 若三步后仍不经济 → **回 Cut Map**：把 180° 环绕改成"他走过后一个反打大屏的切镜 + 他回头的过肩镜"，用剪辑获得同样信息，这是正当改戏而非失败。

## 示例 4　导演层：Probe + Cut Map + 粗剪反推

### Probe（S1，规划前只验最高风险）

本片有个平台没验证过的难点：**多人重叠抢话 + 温柔零情绪的系统女声画外切入**。完整规划前先做 1 条 3 秒探针：两个观察员同时抢话、系统女声插入"请遵守发言秩序"。
结论：单人内嵌口型可用，但**两人精确重叠做不稳** → 改设计：重叠句拆成两人各自的短镜分别生成再剪，系统女声走画外（C 级，不做口型）。探针通过后才展开全片契约，避免 70 个镜头写完才发现不行。

### Cut Map 片段（S3，不写提示词）

| 镜号 | Beat/叙事任务 | 预估 | 必须/Candidate | 口型级 | 预算 | 路线 | 首帧 |
|---|---|---|---|---|---|---|---|
| SH-037 | 群体第一次互揭，两人抢话 | 3s | 必须 | A | L2 | 拆分两镜 I2V | SET-03+群演存帧 |
| SH-038 | 系统女声切入，全场静默 | 2s | 必须 | C | L1 | I2V，声音画外 | SET-03 |
| SH-039 | 12号真话固定长镜 | 6s | 必须 | A+ | L3 | 合成首帧 I2V+尾帧 | 见示例1 |
| SH-040 | 众人回避目光的反应群像 | 2s | Candidate | B | L1 | I2V，侧脸规避 | SET-03 |
| SH-041 | 大屏计票跳动（信息后期） | 1.5s | 必须 | C | L0 | T2V，数字纯后期 | 无 |

### 粗剪反推（S7）

- **删**：SH-040 反应群像在粗剪里和 SH-039 的结尾停顿信息重复 → Candidate 标记删除，省下整组群演镜头。
- **补**：系统女声切入后缺一个"被打断者把话咽回去"的特写，否则静默没着落 → 回 S4 补一条 SH-038b（B 级侧脸，低成本）。
- **改**：素材里 SH-039 演员停顿比预估长 1 秒反而更有力 → 以素材为准，顺延后续时间码，**Beat 由素材反推**，不逼她按纸面秒数演。

## 示例 5　声音、台词与口型分级（内嵌规范）

台词书写：`【角色】（语气·语速·情绪·气息·停顿）台词原文`，标点承担节奏：`——` 被打断、`……` 迟疑、`？` 反问；多人用 `（抢话）（重叠）` 标注。

- **A+（正脸核心，严格同步、多生成备选）**
  【小乔】（深吸气·语速放慢·一字一顿·声音很稳）这条信号——是我推上去的。（停顿）我负责。
- **A（正脸，基本同步）**
  【周启】（低声·语速平·几乎没有起伏）我早就不看评论了。
- **B（侧脸/遮挡/反应镜，主动规避正脸口型）**
  王诚侧脸看向邻座，嘴部处于阴影，只给喉结动了一下与回避的眼神；台词可后期贴。
- **C（画外系统声/群杂/无声，不做口型）**
  【系统女声·画外】（温柔·零情绪·匀速）检测到违规发言，已为您记录。（画面停在 TALLY 红灯，无人物正脸）
- **抢话/重叠（探针证明单条不稳，拆分生成再剪）**
  【32号】（急·提高音量）可她明明—— ／ 【17号】（抢话·重叠半句）你先别装！

枪声、计票提示音、人群嗡鸣等作为声音设计写清声源与进出点；不自动铺煽情 BGM。武器来源、准备、操作与血腥慢动作一律不展示，枪响只给 TALLY 灯与人物反应。

## 示例 6　迁移到任意题材（方法与题材无关）

控制信号分析不绑定"直播审判"。换成一个雨夜便利店回头镜头，流程完全一致：

```
SHOT: SH_023（雨夜便利店回头）
DIRECTOR INTENT: 慌张→突然犹豫；第一次起逃跑念头；关键瞬间=门口回头
MUST CONTROL: 身份 HIGH / 服装 HIGH / 回头动作 HIGH / 相机后拉 HIGH / 空间 MEDIUM / 雨 MEDIUM
CAN DRIFT: 雨滴形态、路人、背景小物、头发细节、灯牌细节
BUDGET: L3
STRATEGY: 角色参考 + 便利店场景静帧 + 相机后拉运动代理(白膜/手机) → 代理引导 I2V
PROMPT（相机轨迹交给代理后很短）:
  She hesitates for a fraction of a second, then turns toward the doorway.
  Restrained performance, subtle breathing, rain catching the fluorescent light,
  natural cinematic motion.
```

- **无对白 MV / 广告**：口型级全 C，预算花在 identity 与风格参考图上，节奏交给音乐点位与粗剪。
- **动作 / 追逐**：identity 通常降级，**运动复杂度升 HIGH**，主力信号变成运动代理、首尾帧、动作参考视频；接触点用插入镜分镜，别让一段同时承担多人+复杂运镜+形变（完整做法见示例 7）。
- **纯静帧 / 海报**：不进入视频引擎，只取摄影/灯光/材质层，不写运镜与时间轴。

## 示例 7　动作 / 打斗专场：三人交锋的代理驱动 + 多机位链式生成（含 PBR 材质）

> 题材：奇幻写实质感的"蚀羽之夜"，血月光下的石祭坛。**A 紫瞳剑士**（祭坛左侧，长剑）自左向右冲刺攻向后方中央的 **B 白发羽爪者**；**C 持镰裁决者**（右侧，长镰）从右拦截。整段约 9 秒、5 个剪辑镜头、3 个机位职能。固定宽景保持实时时间，**不使用子弹时间**，靠接触点插入镜与命中顿帧给力度。
> 动作戏与文戏的根本差别：**identity 降级、运动/空间/形变升级**。最难控制的不再是"脸像不像"，而是"三个人的走位、武器归属、接触与受力、跨镜动作相位"。

### 7.1 整场 Cut Map（先拆机位与相位，不写提示词）

| 镜号 | 机位职能 | Beat / 动作相位（起→止） | 预估 | 预算 | 路线 | 接点资产 |
|---|---|---|---|---|---|---|
| AC-01 | 固定空间主机位（宽景，略低角度） | A 拧腰蹬地起步冲刺，C 自右转身横镰拦截，B 在后方抬爪 | 2.5s | L3 | 白膜走位代理→代理驱动 I2V | 尾帧=A/C 即将进入有效距离 |
| AC-02 | 侧向接触点机位（中近景，贴地仰拍） | 长剑与镰杆咬合相抵，刃口擦出细火星，两人角力 | 1.8s | L3 | 武器道具参考+接触代理→I2V | 首帧对齐 AC-01 尾帧相位 |
| AC-03 | 表演/反应机位（中景，过 A 肩看 B） | B 自后方下压羽爪，A、C 同时受迫下沉，台面受力 | 2.0s | L2 | 角色参考+受控首帧 I2V | 承接 AC-02 角力末态 |
| AC-04 | 细节/插入机位（大特写，台面接触点） | 祭坛石盘在三方受力下下陷、裂纹爬开、粉尘迸起 | 1.2s | L2 | 场景材质参考+首帧 I2V（可 V2V 加强） | 裂纹位置与 AC-03 受力点一致 |
| AC-05 | 回到固定主机位（宽景） | 三人同时被反震分开、各自卸力缓冲，披风与尘滞后回落 | 1.8s | L3 | 代理驱动 I2V+尾帧 | 末态交接下一场 |

铁律：**同一招在成片时间线上只发生一次**。AC-01 的冲刺不在 AC-02 重演；AC-02 只接"咬合之后"。三个机位是对同一事件的不同覆盖，靠动作相位（Cut on action）与视线/受力方向剪辑，不是把同一段打斗顺接三遍。轴线固定：A 始终在屏幕左、C 在右、B 居后中央，血月主光方向全场不变。

### 7.2 关键接触镜 AC-02 的完整走查

**① Shot Contract**
- 叙事任务：让观众看清"拦截成立、双方兵器咬合"，这是整场动作的力学支点。
- 首态 → 末态：A 剑自左下斜上撩、C 镰杆横置迎击 → 兵器死死相抵、两人手臂因角力微颤、刃口一线细火星迸落。
- 不可失败项（≤3）：①武器归属不互换（A 是长剑、C 是长镰，各一把）；②接触真实、有受力形变与停顿，不穿模、不空挥；③刃口是冷钢质感而不是发光光剑。

**② Control Analysis（七维）**

| 维度 | 等级 | 说明 |
|---|---|---|
| transformation 形变/接触 | HIGH | 兵器咬合、甲片/布料挤压、火星，动作戏最易翻车 |
| spatial 空间/轴线 | HIGH | 两人左右关系、兵器夹角、与后方 B 的距离 |
| camera 相机 | HIGH | 贴地仰拍 + 命中瞬间极短后坐/顿帧反馈 |
| transition 跨镜衔接 | HIGH | 首帧必须接 AC-01 冲刺末态，末态交 AC-03 |
| composition 构图 | MEDIUM | 接触点居中、刃身前景夸张 |
| identity 身份 | MEDIUM | 定妆角色，但接触镜里脸是次要的，靠服装/武器认人 |
| performance 表演 | LOW | 无台词，只有发力的身体（喝斥走声音，不做口型，C 级） |

**④ Control Budget → L3**：运动复杂 HIGH + 衔接 HIGH + 形变 HIGH。L3 但**不堆信号**——无台词所以不上音频口型，身份只 MEDIUM 所以角色参考给一张即可，把预算集中给"动作代理 + 武器材质参考 + 首尾帧"。

**⑤ 控制信号分配 + Router（链式，而非一段生成整场）**

| 控制需求 | 交给的信号 | 从 Prompt 拿走什么 |
|---|---|---|
| 两人走位、兵器轨迹与时机 | **运动/空间代理**：白膜/火柴人三人粗演，或手机找两人拿道具走位拍的粗视频 | 删掉"先向左半步再转腕"这类动作编排文字 |
| 相机贴地仰拍 + 命中后坐 | 代理里的相机路径（命中瞬间沿受力方向一顿） | 不写运镜参数 |
| 长剑/长镰/甲胄的材质 | **武器与服装材质参考静帧**（定道具时单独出图锁定） | 不堆"高精金属/8K"空词 |
| 祭坛空间与血月光向 | 场景 establishing 图 | 不罗列环境 |
| 咬合首态 / 角力末态 | 首帧（=AC-01 尾帧）+ 尾帧 | 不描述起止姿势 |
| 接触形变、力度、火星、表演张力 | **留给 Prompt** | 这是动作 Prompt 真正该写的 |

**路线（Router）**：运动代理 + 武器/场景参考 + 首尾帧 → **代理引导 I2V**；接触点形变若不到位，单独对咬合区域做 **V2V / Mask 局部加强**，不重生整条。
**明确禁止**：纯 T2V 一段生成"三人混战+多机位切换+火花特效"（必然武器互换、穿模、匀速软绵绵，对应缺陷 D8 超载 / D9 融化 / D10 道具人数穿帮）。

**⑥ 最小有效 Prompt（运动、材质、构图都被信号锁走后，只写力度与状态变化）**

> 贴地仰拍，长剑自画面左下斜撩而上，长镰镰杆横置迎击，两件兵器在画面中部死死咬合。发力自腰胯而起、经肩臂传到手腕与兵器，两人几乎同时到位、手臂与上身因角力出现先后时滞的微颤而非整体平移；咬合瞬间画面极短地一凝、迸起的细火星悬在半空，随后才沿刃口滑落炸开。A 的皮甲片在受力处局部内凹、粗布袖口被挤成深褶、非刚体的披风与发束带一点二次晃动；长剑身是哑光冷钢、仅刃口一线窄而锐利的高光，镰刃反光更散，金属相抵只擦出少量细火星（无附魔、没有火球与光效）。背景祭坛花岗岩颗粒与血月冷光保持静止，接触点前景刃身近大远小、远处柱廊沿真实透视收束。命中后镜头沿受力方向极短后坐、随即阻尼回正。
> 声音（声音设计，非口型）：刀锋破风 → 金属交击的一记脆响叠加低频闷震、甲片碰撞哗啦、两人压抑的喝斥与粗重呼吸、空间长混响；无背景音乐覆盖。
> 负面：不要匀速耍花、不要空挥与穿模、不要武器互换或多出兵器、不要刃口整条发光/激光剑、不要爆炸火球与漫天火花、不要子弹时间全程慢放、不要镜头无差别乱震、不要人物正对镜头做口型。

> **打斗力度六要素自检**（写动作 Prompt 时逐条过，来自 `toolbox-rendering-3a.md` 第4节）：①速度力量=蓄力慢→爆发快→收势缓冲，非匀速；②力度叠加=核心躯干→肩→臂→手/武器逐级传导、扭腰送肩甩臂有时滞；③受击形变=甲片内凹/布料挤压/肌肉面部甩动、非刚体二次晃动；④冲击连锁=细火星→台面粉尘裂纹→远处挂布延迟掀起；⑤动量连续=重心/披风发丝/镜头共享同一速度矢量，急停有前冲惯性；⑥镜头受击反馈=重击沿受力方向后坐 + 命中顿帧（画面极短一凝、碎屑悬停随后炸开）后阻尼回正，不无差别叠加。
> **数字→视觉锚点**：成品区不写"顿帧 0.1–0.2 秒"，写"命中瞬间画面极短地一凝、碎屑悬在半空随后猛然炸开"。

**⑦ PBR / 3A 材质怎么锁（这是"一堆专业词汇"的正确用法）**

材质词不堆在视频 Prompt 里赌模型，而是在**定道具/定妆静帧阶段**用参考图锁定，视频 Prompt 只描述材质的**状态变化**（受力、磨损、沾尘）。

| 材质 | 定妆静帧锁定的 PBR 特征（出道具图时写） | 视频里只写变化 |
|---|---|---|
| 长剑（冷锻钢） | PBR 金属度高/粗糙度中低、法线贴图微凹凸、清漆层、刃口**窄而锐利的高光线**、剑身磕碰露底、指纹油污 | 咬合处细微划痕、刃口一线火星 |
| 长镰（钝重兵械） | 哑光金属 + 木柄缠绳，**反光散而不锐**、铆钉与做旧 | 受力时杆身微弯回弹 |
| 皮甲 / 革护具 | 植鞣革纹理、皮甲片层叠、缝线毛边、铆钉、握持与关节处包浆油边 | 受力点甲片内凹、褶皱 |
| 皮肤 | **SSS 次表面散射**（耳际/指缝透光）、毛孔细纹、汗渍皮脂高光、皮下静脉；禁磨皮塑料/蜡像感 | 发力时肌肉隆起、颈侧筋线、薄汗 |
| 祭坛石盘 | 花岗岩颗粒与层理、受潮色差、GI 全局光照、AO 环境光遮蔽与接触阴影 | 受力下陷、裂纹、粉尘 |

统一原则：**同一画面反光逻辑一致**（金属高光比石材更锐、暗部仍有反射），磨损位置符合握持处/关节/刃口；血月冷光下用主:辅≈3:1–8:1 的大光比。无附魔的写实打斗，金属碰金属可有少量火花，**布料与人体接触不产生金属火花**。细节按景别分级：接触大特写取材质微划痕/针脚/毛孔，中景取甲片大褶皱与武器轮廓光，宽景取宏观光影、轮廓剪影与体积雾。

### 7.3 动作戏的三条总结

1. **运动/空间代理是动作戏的主力信号**，不是 Prompt：走位、兵器轨迹、相机后坐都先在白膜/手机粗演里定死，模型只负责把代理"拍成"成片。
2. **多机位是分别生成、后期按相位剪辑**，从不让模型在一段里切机位；接触点单独出插入镜，既保力度又降单段负荷。
3. **PBR 材质靠道具/定妆静帧锁定**，视频 Prompt 只写受力、磨损、沾尘这类**状态变化**；特效遵守材质来源（无附魔不产火球）与"起因→预兆→触发→峰值→衰减→残留"的生命周期。
