## 1. 核心渲染与材质

- **渲染**：PBR 物理材质、全局光照 GI、环境光遮蔽 AO、接触阴影、光线追踪反射/折射、屏幕空间反射 SSR。
- **皮肤**：SSS 次表面散射（耳/鼻/指缝透光）、毛孔与细纹、绒毛汗毛、皮脂高光区（T 区/肩）、皮下静脉、瑕疵与不对称。写实禁用磨皮塑料感与蜡像感。
- **织物/皮革**：经纬织纹、缝线毛边、褶皱受力方向、汗渍水渍、做旧褪色；皮革有摔纹、油边、折痕与压痕。
- **金属**：法线贴图微凹凸、各向异性拉丝反光、清漆层、锈蚀/氧化斑、磕碰露底、指纹油污；刃口高光窄而锐利，钝器反光散。
- **石/木/陶**：石材颗粒与层理、受潮色差；木材年轮、劈裂毛刺；陶器开片、釉面垂流、崩口。
- **能量/特殊材质**：自发光菲涅尔边缘光、体积内透、表面符文流动、半透明晶体内絮状物。

材质统一原则：同一画面内材质反光逻辑一致（金属比石材高光更锐更暗部反射），磨损位置符合使用习惯（握持处、关节、刃口、鞋底）。

## 2. 大气与后期（候选，按 V9 颜色与阶段边界选择）

- 大气：体积雾、高度雾分层、体积光/丁达尔光束、尘埃悬浮、雨幕/雪雾、地表热气扭曲。
- 后期候选（并非默认套用）：依据素材/输出流程评估 ACES 相关色彩管理是否适用；依剧情和实拍/生成画面需要，选择整体平衡、可选 S 型或低反差曲线、白平衡与局部色彩、颗粒或光学效应。ACES 不等于万能滤镜；未经素材和色彩空间确认不得宣称转换已完成。
- 光比建议：主光:辅光≈3:1～8:1，夜景/戏剧性取大光比，COS 棚拍取 2:1～3:1。

## 3. 细节分级（按景别取用，禁止全量堆砌）

| 景别 | 启用细节 | 舍弃 |
|---|---|---|
| 特写（面部/胸像/接触点） | 皮肤纹理、汗毛、毛孔、材质微划痕、眼神光、织物针脚 | 大场景、体积雾层次 |
| 中景（半身/全身） | 服装大褶皱、主材质感、武器轮廓光、动作动线 | 毛孔级细节、远景氛围 |
| 远景（大场景/多人） | 宏观光影、体积雾层次、整体色调、轮廓剪影、大气透视 | 个体材质微细节 |

## 4. 打斗力度六要素（C 类核心；本节秒数为示意性分镜参数，默认只进说明区【分镜参考】；用户要求或模型支持时间码时允许精简时间轴进成品①）

1. **速度与力量感（按需）**：可采用蓄力慢 → 爆发快 → 收势缓冲，也可用克制匀速与突然中断表达控制力；不强制全片或每招变速。可参考蓄力→快速加速→接触→惯性衔接的非匀速节奏；具体时长按动作复杂度与模型能力调整，勿强制套固定曲线。
2. **力度叠加**：力量由核心躯干 → 肩 → 臂 → 手/武器逐级传导，表现为扭腰、送肩、甩臂的先后时滞，而非整个人平移。
3. **受击形变**：命中点肉体挤压凹陷、布料剧烈挤压褶皱、铠甲局部内凹、面部肌肉甩动；非刚体要有二次晃动。
4. **冲击连锁**：冲击波外扩 → 碎屑/血雾（写实降级为尘土/火花）→ 地面尘土与裂纹 → 远处挂布/树叶延迟被掀起。
5. **动量连续**：角色重心、武器轨迹、披风发丝拖尾、镜头运动共享同一速度矢量；急停有前冲惯性，转向有减速—再加速。
6. **受击反馈（镜头）**：轻击短促震动；中击沿受力方向后坐；重击可选短促镜头后坐、局部慢放或命中顿帧 Hit-Stop（约 0.1–0.2s 仅供后期参考），随后阻尼回正；不要三者无差别叠加。禁止软绵绵、匀速顺滑、命中无反馈。

## 5. 动态特效词库

> 调用总原则：服务动作动线与物理逻辑，集中在接触点，禁止无意义堆砌与全屏糊屏。

**粒子系统（不同来源可并存，按对象、触发与层次选择）**
- 自然：扬尘、尘环、沙幕、水雾、雨滴溅射、雪花卷动、落叶/花瓣、火星余烬。
- 战斗：金属火花束、碎屑迸射、碎石弹片、断纤维、革屑、铠甲漆片。
- 能量：元素光点、符文碎屑、能量丝线、光尘上浮、电弧跳点、冰晶碎钻、暗影絮流。
- 行为：汇聚（蓄力吸附）、迸射（命中）、拖尾（移动）、飘落（余韵）、悬停（静止场）。

**拖影 / 残影（有实际高速或世界观来源时使用，沿动作动线）**
- 类型：半透明重影、光边轮廓残影、运动方向拉伸虚影、武器弧线光轨、披风/发丝连续拖尾、冲刺地面尘尾。
- 写实克制（偶发、短、低透明度）；游戏/奇幻可强化为多重重影与光轨；禁止全屏鬼影。

**运动模糊（受快门/快门角控制）**
- 用词：方向性运动模糊、径向模糊（旋转/冲刺）、速度模糊、冲刺模糊、背景径向拖影、镜头抖动模糊。
- 写实：仅高速段、沿运动矢量、背景强于主体以保主体清晰；静帧慎用。

**冲击波 / 激波**
- 环形气浪、地面尘环外扩、空气折射扭曲环、水面/积灰被压平再外推、碎玻璃放射状迸开、近处物体延迟掀翻。

**破坏 / 碎屑 / 环境交互**
- 材质反馈：木裂纤维外翻、石碎成块带粉尘、金属凹陷回弹、陶片崩裂、玻璃蛛网纹后碎裂。
- 交互：踩碎石板、撞断木梁、挑断绳索、借力蹬墙、砸地龟裂半径外扩、扫倒道具。

**能量 / 魔法 / 科幻（奇幻科幻按世界观开放组合，不套主元素种数上限）**
- 能量束、护盾六边形波纹、符文阵展开、空间扭曲折射、传送涡旋、电磁弧、推进器焰、全息故障、子弹时间环场粒子（仅在叙事确实需要延展主观时间时使用，先过 V9 反惯性审查）。

**时间 / 镜头后期（速度数字必须配视觉特效；帧/秒参数仅供分镜参考，不进成品①）**
- 候选且非套餐：命中顿帧、子弹时间（主体清晰 + 环境粒子缓行）、快进抽帧、局部慢放、速度线、冲镜畸变、冲击帧（短促高对比白闪/黑场）。逐项先说明它解决的叙事/动作可读性问题，优先探索常速、固定全景、声音休止、环境连锁后果等不同机制；不在未知模型上保证精确帧数。

## 6. 特效调度模型（V6 废除固定数量配额）

不再设置「主元素≤1、粒子≤2、速度表现≤2、冲击波≤2、运镜≤2、透视≤2」这类通用配额。预算真正约束的是**同一时刻模型需完成的交互量、主体被遮挡程度、素材来源矛盾和观看注意力**，而非整镜头出现的效果种类。多个不同对象的效果可以并存；同一对象的效果可以随事件顺序变化；不同能力模型以实测决定是否拆镜。

| 检查对象 | 允许的复合表现 | 需要处理的冲突 | 修正顺序 |
|---|---|---|---|
| 特效来源 | 刀擦石火星、脚踩水水花、骨甲受击骨屑、祭坛异变空间折射并存 | 材料接触不成立、同物体属性无解释地变更 | 补因果／魔法规则；不成立则移除该项 |
| 画面焦点 | 背景体积雾与前景接触碎片并存 | 火花雾尘同时遮住攻击、接触或脸 | 先调整时间、方向、大小、亮度或构图，再考虑删减 |
| 风格属性 | 金属写实反射＋超现实天空＋哥特建筑 | 共用光源与透视无解释地互相矛盾 | 明确元素分工、共同光照或超现实局部规则 |
| 镜头与速度 | 跟拍、焦点转移、局部运动模糊有顺序地组合 | 同一瞬间既长焦压缩又广角扩张，镜头无过渡地瞬移 | 交代变焦/剪辑/运动先后，必要时拆镜 |
| 模型负荷 | 多层特效但主体动作简单 | 多角色连招＋高速绕拍＋遮挡特效同帧抢占注意力 | 先保证动作事件，重排效果时序或分段生成 |

重点效果用「起因→预兆→触发→峰值→衰减→残留」写生命过程，简单效果只需几个真实可见阶段。删去一种合理效果必须有具体冲突原因，不得因为超过历史配额而删除。

## 7. 透视夸张与特写透视

**C 类动作接触点按叙事需要选择标准透视或适度夸张；A 类写实面部默认自然中长焦；D 类标准透视优先。不要强迫使用鱼眼或组合透视。**

- 工具箱：超广角、鱼眼畸变（仅冲镜/环绕瞬间）、近大远小、透视缩短（foreshortening）、贴地仰拍、俯冲透视、前景夸张放大、背景透视拉远、肢体/武器冲镜放大、纵深拉伸。
- C 类动作特写：有必要时选一种可解释的透视手法，例如贴地仰拍或前景近大远小；不同焦段效果不能无过渡地同时指定。鱼眼和强烈冲镜仅按明确视觉意图启用。
- 输出写法（进成品区，自然语言）：`[特写透视]` 不出现标签，直接写「刀刃从镜头前方斜刺而入、刃身占据画面下半、刀尖夸张放大，远处廊道沿真实透视收束」。

## 8. 环境反馈与物质外溢选项（C/B 按材质与题材触发；A/D 默认关闭）

外溢是可选的动作视觉延伸：写实徒手格斗允许完全没有粒子/能量；环境反馈必须有接触、风、雨或其他可见来源；超自然外溢须有明示的世界观属性。可同时有不同来源或有世界观联系的多种属性与外溢；用对象归属、颜色层级与出现时序保持清晰，不按「每镜头一种附魔／两种形态」机械削减。

- **速度外溢**：高速→残影/拖影/方向性模糊/速度线；冲刺→残影 + 地面尘尾 + 风压；急停→惯性拖影 + 尘土前溅；空中→气流拖尾 + 衣摆发丝拖尾。
- **武器攻击（按附魔主元素）**
  - 暗影：黑红暗影焰、暗影粒子、黑色火星、空气扭曲。
  - 血色（写实降级处理）：暗红符文光、红能量粒子、暗红剑气拖尾（避免直白血雾）。
  - 冰霜：冰晶碎钻、寒气白雾、霜花蔓延、冻结痕。
  - 风暴/雷：电弧粒子、蓝色电火花、雷暴环、电弧拖尾。
  - 火焰：火焰粒子、火星、热浪扭曲、火焰拖尾。
  - 神圣：金色光尘、圣光粒子、光晕、净化波纹。
  - 自然：藤蔓、叶片、花瓣、花粉光粒。
  - 无附魔：金属碰撞金属时可有少量火花；普通布料、人体接触不生成金属火花；高速挥刃可使用少量反光/运动模糊，非必选。
- **拳脚/体术**：拳掌→肌肉与衣料挤压、躯干位移；踢腿→支撑脚移动及接触反馈；肘膝→近距离身体受力；超能力题材再按需增加气浪或能量。
- **格挡/碰撞**：金属兵器碰撞→可有少量金属火花；木质盾牌→木屑或振动；魔法护盾→按设定给波纹；撞环境→由真实材质与撞击强度决定有无碎屑。
- **蓄力**：普通武器蓄力→手部收紧、身体旋转、刀身受光；身体蓄力→肌肉绷紧、重心下沉；有魔法设定时才加入能量粒子、符文或法阵。
- **移动/环境**：普通踩踏→相应尘土/水花/草叶反应；滑铲→与实际地面材质对应的摩擦；攀爬借力→鞋底、手掌与接触面的真实反应；只有力量足以破坏物体时才添加碎屑裂纹。

## 9. 多风格元素分工与视觉母题（V6）

具体风格由用户指定，本库只给方法，不预设风格；可响应用户对特定作品美学的参考要求，但应避免无意照搬标志性镜头和已有故事元素。

1. **主题母题**：从剧情提炼一句可视觉化的母题，例如「吞噬」使天空阴影、祭坛骨架与构图负空间在不同元素上呼应。明确世界观允许哪些物理异常。
2. **元素分工**：人物、装备、建筑、天空、生物、环境、光照、特效、构图分别采用最合适的风格特征，例如人物写实重量、建筑哥特肋拱、天空超现实错尺度、构图古典绘画明暗层次。
3. **细节实例化**：不写「哥特＋超现实＋写实」空标签；写出尖拱如何变成骨肋、天空尺度如何错位、皮革磨损和铁器反射如何可见。
4. **分层与统一**：前/中/背景分别承担信息，角色与不同风格元素共享光源、投影与基本透视；有意违反物理的部分提供局部世界观规则。配色只描述主次与分布，不默认 40/30/15/10/5 数字模板；后期词仅在能指向具体变化时使用。
5. **跨镜头演化**：保留材质与视觉母题，一次镜头升级只在剧情触发时发生，允许不对称、反差、留白以及不同画面元素各有特效，避免把全片做成统一模板。

可交互环境点（不擅增武器，服务动作动线）：
- 石质：牌坊、石柱、石梁（击碎/倒塌/撞击/借力）。
- 悬索：铁链、绳索、木板（断裂/挑断/荡开/崩塌）。
- 悬浮石：悬浮碎石、巨石（踩踏/击飞/撞击/碎裂）。
- 木质：栈道、屋檐、木桩、木箱（踩碎/踢飞/刺穿）。
- 瓦陶：屋顶瓦、陶罐（踩碎/踢飞/碎片）。
- 植被粒子：花瓣、沙尘（卷气流/遮挡/粒子）。
- 符文机关：石壁符文、残破机关（击中释放冲击波、短暂照亮）。
- 地形：峡谷、深渊（跳跃/滑翔/坠落/借力）。

| 1 秒 0→Mach 1+ / 超音速 | 爆发瞬间身形在原地消失、只留一道残影，空气被撕出锥形白雾，远处旗帜在人已离开后才被掀起 |
| 人物:场景 = 1:1000 | 人物在画面中只剩一个小点，巨物从画面底部一直延伸到看不见顶端 |

| 前景:中景:背景 = 1:10:100 | 近处一柄剑的护手清晰可辨，十步外人已变小，远山没入雾中只剩轮廓 |
| 冲击波半径 10 米 | 气浪把周围一圈人同时掀退、最近的旗帜与摊位成片倒伏 |
| 地面龟裂半径 5 米 | 落点裂纹爬满整块石板、蔓延到周围几人的脚下 |
