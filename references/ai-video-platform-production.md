# AI 视频平台生产：平台适配、参考图、台词内嵌、口型分级与低成本批次策略

> 本文件解决导演方法论"最后一公里"：把导演分镜翻译成具体 AI 视频平台（即梦 / 可灵 / 海螺 / Vidu / Runway / Veo / Sora 等）能稳定执行的图生视频生产。导演语言决定"要什么"，本文件决定"怎么低成本、高一致性地做出来"。
> 平台能力更新快，**凡涉及具体积分、时长上限、参数名、支持格式，一律以当期平台实测为准，不在此写死数值**；下列是与平台无关的生产方法。

## 1. 先判定平台能力，再决定生产路径（开工前必做）

不同平台在五个维度能力不同，直接决定分镜怎么拆、台词怎么进、要不要分轨：

| 能力维度 | 要实测确认什么 | 影响的生产决策 |
|---|---|---|
| 图生视频首帧 | 是否支持上传参考图/首帧；能否同时给角色+场景多张 | 决定"定妆照保脸"方案是否可行 |
| 尾帧/首尾帧 | 是否支持尾帧锁定、首尾帧续写 | 决定跨镜动作相位衔接方式 |
| 时长 | 单段可生成秒数、能否续写 | 决定一个 Shot 是否要拆段 |
| 台词/音频/口型 | 是否支持台词内嵌生成、是否带配音、口型同步质量、是否支持多人/抢话 | 决定台词内嵌还是分轨配音（见第4节决策树） |
| 运镜/语言 | 对中文运镜词、焦段词的识别度；是否易乱加运镜 | 决定提示词用中文导演句还是关键词 |

**测试片原则**：首次使用某平台、或某平台能力未知时，先用 1–2 个**有代表性的难镜**（一个带台词正脸、一个带动作衔接）做最小测试，验证口型/保脸/运镜/时长，再批量。**仅当**用户已实测过该平台同类镜头、或明确要求跳过、且镜头类型在已验证范围内时，才可跳过测试直接批量——跳过时在交付说明注明"未在本平台验证"。不因省积分而跳过对全新能力的验证。

## 2. 参考图物料体系（图生视频保一致性的核心）

AI 视频跨镜"变脸/变装/变场景"的主要解法是**先用图像工具建立资产库，再用图生视频首帧锁定**，而不是在每段提示词里反复文字描述长相。

**资产清单（开工前先备齐）**：
- **角色定妆照**：每个有台词/近景的角色一张，固定年龄、发型、服装、肤色、标志物（胸牌、耳返、眼镜）。统一景别（建议半身 3:4）、统一光向，便于跨镜复用。
- **场景 establishing 图**：每个主要场景一张大全景/空镜，固定空间布局、光源方向、色温、关键地标（出口、屏幕、TALLY 灯）。
- **关键道具/装置图**：推动剧情的道具（按钮、装置、对讲机、特定机器）。
- 配角/群演若无定妆照，标注"现场生成"，第一次跑出合适脸后**存帧当后续参考**。

**首帧组合规则**：
- 单人近景 → 角色定妆照为首帧；场景靠提示词带。
- 单人在特定场景 → 角色定妆照 + 场景图（平台支持多图时）；只支持单图时，用角色图当首帧、场景写进提示词，或先用图像工具把角色合成进场景再当首帧。
- 多人对话 → 以主说话者定妆照为首帧，或先用图像工具出"双人/多人同框构图图"当首帧，避免模型自由排列人物位置。
- 场景空镜/群像 → 场景 establishing 图为首帧。

**跨镜衔接**：优先用上一镜的**实际尾帧**（或尾帧附近截帧）当下一镜首帧，锁定动作相位、服装污渍、道具状态；拿不到尾帧时，在下一镜提示词开头**显式复述上一镜末态**（谁在哪、什么姿势、手里有什么、光从哪来）。

## 3. 导演语言 → 平台提示词转换

- **最小有效提示词，不是每层都写**：先放不可失败项（身份/首帧锚点 → 本镜唯一主事件 → 关键口型/末态），再从下列层里**只挑会影响本镜成败的 2–4 层**：摄影（焦段/景别/景深/构图/机位）、运镜（含目的）、灯光（光位/光质/光比/色温）、色彩（整体/局部/跨镜）、表演（可观察身体，不写情绪形容词）、材质、声音/台词。A+ 正脸长台词才值得多层展开；C 级空镜/群杂/UI 一两句即可。完整规则见 `solo-workflow.md` 第8节。
- **中文平台优先用完整导演句**，不是英文 SD 关键词堆砌。
- **每个专业词紧跟可见结果**：写"伦勃朗光"要补"近侧脸颊三角亮斑、远侧沉阴影"；写"浅景深"要补"背景虚成散景"。模型只认画面结果，不认术语头衔。
- **一镜一主事件**：单段不要同时要求 复杂多人交互＋准确台词口型＋复杂运镜＋复合 VFX；超了就拆 Shot（见 sound-timing-editing 的复杂度分级）。
- **可读文字一律后期**：多数模型生成的汉字会乱码。屏幕 UI、计票数字、招牌、短信、片尾字幕统一写"内容后期合成，画面只留发光矩形/占位"，不让模型产可读中文（剧情明确需要乱码除外）。
- **不写模型做不到的精确指令**：精确秒级时间码、多机位镜内切换、像素级二级调色、指定 LUT/示波器，都不承诺；改为可修剪的前后缓冲 + 后期。
- **负面提示**：按平台支持给中文负面词（见 glossaries 第10节），只写本片真会翻车的少数项（如不展示武器来源、不要赛博朋克、塑料脸、多手指），不无脑全堆。

## 4. 台词、配音与口型：内嵌还是分轨

**决策树**：
1. 平台支持台词内嵌生成、带配音、且口型在测试片中达到可用 → **台词内嵌进视频提示词**（省一次分轨配音成本），按下述规范写。
2. 平台口型不可用、但支持画面生成 → 画面生成时人物按台词节奏做说话动作，**配音分轨**，后期对口型；或正脸台词镜改用侧脸/背影/反应镜规避（见口型分级 B）。
3. 平台不支持音频 → 画面与声音彻底分轨，分镜只保留声音导演意图。
4. 多人重叠/抢话/精准气口，单条内嵌做不稳时 → 该句分轨或拆成两人各自的镜头分别生成再剪。

**台词内嵌书写规范（台词作为提示词的一部分，放在画面描述之后）**：
- 格式：`【角色】（语气·语速·情绪·气息·停顿）台词原文`。已有剧本台词**逐字保留**，不改写。
- **语气语速前置**：在括号里给可听的导演指示，如`（语速慢，平，像陈述天气）``（拔高，急，委屈）``（压低，极确定，不喊最大声）`。
- **标点承担节奏**：`——`表被打断或话没说完；`……`表迟疑/停顿；`？`表反问；句号短停、逗号气口。把停顿写进标点和括号，不写"停顿2秒"这种模型不认的指令。
- **抢话/打断/重叠显式标注**：
  - 抢话：`【B】（抢话，压过A）……`
  - 打断：A 的话用`——`收，紧接 B。
  - 重叠：标注`（与上句同时，重叠约1秒）`，并尽量把重叠两人拆到不同镜头分别生成，剪辑叠声。
- **画内/画外/系统声分清**：画外音标`【角色·画外】`，镜头可停在听者脸上（反应镜）；系统/广播声标`【系统女声·PA】`且**不对应任何人物口型**。
- 一句台词给：说话者＋原文＋对谁/想让对方做什么＋（必要时）潜台词＋音量音高语速气息停顿＋可见表演。参考 cinematography 第11节。

## 5. 口型分级（镜头级，决定积分花在哪）

对每个带声音的镜头定级，分级是**镜头级**不是角色级（同一角色不同镜头级别不同）：

| 级别 | 适用 | 生产要求 |
|---|---|---|
| **A+** | 正脸、核心表演、关键台词/包袱、情绪转折，观众必看嘴 | 严格 lip-sync；优先用支持口型的平台；**多生成几条**选口型与节奏最好的；宁可此处花积分 |
| **A** | 正脸或 3/4 脸、有台词但非核心 | 要求基本同步，生成 1–2 条选可用 |
| **B** | 台词可被遮挡/弱化的镜头 | 主动用侧脸、背影、前景遮挡、听者反应镜、手部/道具插入覆盖，规避口型风险 |
| **C** | 系统/广播画外音、群杂、环境声、枪响、无声镜 | 不做口型；群演不要求逐人对嘴，给群体动作即可 |

把 A+ 镜在分镜/清单里显式标★，作为积分和返工的重点；C 级镜"挑能用就过"，不追求完美。

## 6. 低成本批次生产策略（积分/时间有限时）

**核心思路：不按剧情顺序生成，按"保一致性 + 省成本"分批，剪辑时再按剧情拼回。**

1. **先资产后视频**：先出齐角色定妆照 + 场景图（图像生成比视频便宜得多），锁定全片视觉，再开视频。
2. **按角色/场景集中分批（BATCH）**：把同一角色的所有镜头集中在一批连续生成，复用同一张定妆照当首帧，脸最稳；再换下一个角色。场景同理（控制室镜一批、群像镜一批）。剪辑顺序≠生成顺序。
3. **按口型/难度排优先级**：A+ 关键镜先做、多做几条；A 级次之；B 级用规避构图；C 级最后、一条过。先把"做不好全片垮"的镜头拿下。
4. **群像/大场面降级**：一次只安排 2–5 个前景有动作的人，其余做背景；不要求百人口型；大全景用场景图 + 少量动作。
5. **蒙太奇/空镜/纯后期镜最便宜，放最后或穿插**：城市短切、道具特写、黑屏字幕、UI 数字，成本低，不占用保脸批次。
6. **转场手柄**：每段生成时在动作前后留约半秒可剪缓冲，切点落在真实动作/反应/视线/声音事件上，不按整数秒切。
7. **终局/高潮依赖全片连续性，放最后做**：此时所有人物脸、场景、道具状态都已稳定，最容易接。
8. **建立勾选清单**：按 BATCH 列生产清单，每镜标注 首帧资产 / 口型级别 / 提示词 / 是否已过，做完一批勾一批，避免漏镜重复烧积分。

**分批建议顺序（可按片调整）**：主角全部镜 → 其他主要角色 → 双人/对手戏 → 群像 → 蒙太奇/空镜 → 闪回（可单独做旧质感）→ 终局高潮 → 纯后期片尾。

## 7. AI 生成质检（出片后逐条核，详见 toolbox-checklist G6）

重点查 AI 特有失败：跨镜身份漂移（脸/发型/服装变）、手指数量/肢体融合、说话者与口型错位、无理由运镜/镜头乱跳、中文乱码、群体人数与道具跳变、动作跨镜重演、武器/接触穿帮。发现问题按 production-continuity 诊断表单变量修，不整段重烧。
