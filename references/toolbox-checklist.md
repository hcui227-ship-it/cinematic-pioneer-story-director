# 门控自检清单（内置模块）

> 用法：先过本文件主文「通用硬约束」（对应下方 G0），再按当前任务**只追加相关分组**，不相关组跳过，避免逐条空转。完整剧本模式过适用的 G0–G5 分组。检查条目仅做验证，具体规则以主文及对应内置模块的定义为准；不相关分组跳过。

## G0 通用（每次只核对相关项）

- [ ] V9 创新审查：关键段落是否识别惯性手法并解构功能、评估不同机制、说明跨领域转译和可见/可听结果？是否让整片的创新集中于必要位置，而非每镜套子弹时间、震镜、冲击波或风格乱拼？用户明确指定经典风格时是否尊重？

- [ ] 用户明确要求/禁止与安全约束满足；参考图的明确改造项优先，未改动项保持一致。
- [ ] 主动识别相关专业部门与用户未提及的关键工作；跳过无关部门；真实操作与生成观感分开，不谎称已用示波器校准或完成调色。
- [ ] 内容类型、静帧/视频门控正确；无不相关镜头、节奏或特效强制条款。
- [ ] 角色ID、人数、武器数量及归属、材质与光源来源无自相矛盾。
- [ ] 成品可复制，无内部推理、臆造模型功能及未要求台词；必要数字允许。
- [ ] 输出深度符合快速/专业/剧本/修复，不强迫解释所有预算和词库。

## G1 视频连续性与动作专项（按需，非打斗也检查人物位置与时空）

- [ ] 起止状态账本清楚：双方画面左右/前后、面向、距离、支撑/重心、武器状态、地标、镜头轴线。
- [ ] 连续动作链：预备→进入有效距离→命中/闪避/格挡→受力/落空反馈→余势；无凭空换位或无接触伤害。
- [ ] 动作数量与模型测试表现匹配；时间轴按事件而非强制逐秒，逐秒仅用户明确要求。
- [ ] 主要接触点在镜头内可读；运镜和特写按叙事需要而非固定时长/频率；无多余强制鱼眼。
- [ ] 写实打斗不强制魔法外溢、气浪、残影或破坏；每种火花、碎屑、水花都能解释材质来源；奇幻例外说明世界观规则。
- [ ] 创意检查：关键画面有服务主题的独特视觉构想；多风格按对象分工、共享世界观与照明，不只是罗列风格名。
- [ ] 执行检查：术语紧邻解释；每种效果具备对象、触发、方向、变化及按需消散；多源特效按时间/空间层次调度，不靠固定计数删创意。
- [ ] 跨段首句与末态相接；没拿到尾帧不宣称已经完成帧衔接。
- [ ] 若有实际失败反馈，按故障表优先单变量修改并检查验收项；无成片不声称生成成功。

## G2 静帧

- [ ] 无视频时间轴/运镜；写实人像默认自然透视、肤质与光影；角色设定重视比例/服装一致。
- [ ] 用户没要求时不强制添加环境雾、速度线或多余特效；模型参数须与目标工作流兼容。

## G3 参考图

- [ ] 只锁定可观察特征，不编造遮挡信息；明示改造项按文字走，其余按图。
- [ ] 没有关键冲突时直接交付；冲突影响结果且无法合理假设才提问。
- [ ] 权重数字与外部工具建议仅在实际支持且用户需要时提供，不视为跨模型普适规则。

## G4 叙事、表演与对白（全部故事视频适用）

- [ ] 对白/字幕与动作事件不抢镜；音效口型等精确同步仅在模型明确支持或后期阶段处理。
- [ ] 剧本已有台词必须保留原文；用户仅提供故事梗概并要求创作剧本时可原创适量对白；用户明确要求无台词则不添加。字幕与旁白仅在叙事需要或用户指定时加入。

## G5 输出和适配

- [ ] 交付物与当前阶段匹配（V11）：探索/规划期交 Cut Map＋Probe 结论，不展开逐镜提示词；生产期只对下一步要生成的镜交 Shot Contract（用户明确要可复制提示词时才逐镜给）；后期以 Rough Cut 为准。不默认一次交齐九列全片分镜，也不重复输出两套提示词。
- [ ] 每行是一个真实镜头而非一秒一个镜头；景别、动作、运镜、VFX、光影、末态均可观察且相互一致。
- [ ] 术语按需组合并在同格解释给模型；风格作用到具体画面元素；无固定特效配额，按对象来源与视觉可读性检查。

- [ ] 快速模式仅成品＋必要假设；专业模式只给相关解释；完整剧本按事件给状态接口；修复只改出错部分。
- [ ] 负面词、时间码、权重、模型参数仅在实际支持或用户明确指定时输出；未知功能不捏造。
- [ ] 片段质量审查与实际视频测试结果明确区分。

## G6 AI 视频生成专项（图生/文生视频逐镜核对）

- [ ] **身份一致性**：同一角色跨镜脸、发型、服装、标志物（胸牌/耳返/眼镜）不漂移；首帧是否用了对应定妆照；多人镜头人物位置/人数不跳变。
- [ ] **肢体/手指**：无多手指、手指融合、多余肢体、肢体鬼畜、持握手别错误、道具凭空出现/消失。
- [ ] **口型/台词**：说话者与口型对应，无 A 说话 B 嘴动；A+ 镜严格同步、A 镜基本同步、B 镜有遮挡/侧脸规避、C 镜不做口型；无模型自造的多余台词。
- [ ] **运镜**：运镜与提示词一致，无无理由推拉摇/镜头乱跳/中途变焦；情绪重镜该固定的固定。
- [ ] **文字/UI**：画面无可读乱码汉字；屏幕/招牌/数字/字幕是否按约定留作后期占位。
- [ ] **动作衔接**：跨镜同一动作不重演、不从头再来；动作相位、屏幕方向、轴线接续；接触/受力有因果。
- [ ] **光色连续**：相邻镜光源方向、色温、曝光、肤色不突变（剧情需要的色温变化除外）。
- [ ] **单段负荷**：没有在一段里同时要求复杂多人交互+准确口型+复杂运镜+复合 VFX；超载的已拆 Shot。
- [ ] **成本纪律**：A+ 镜已多生成备选，C 镜未过度返工；批次按角色/场景集中保脸；无重复烧积分的废镜。
- [ ] **平台真实性**：未把未实测的平台能力（精确时长/口型/参数）写成已完成；测试片该做的做了，跳过有注明。
