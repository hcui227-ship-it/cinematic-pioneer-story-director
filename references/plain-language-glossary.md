# 人话对照表（小白术语卡 / Plain-language Glossary）

> 这份 Skill 内部用一套精确的电影/AI 制作术语（S0–S8、Cut Map、Control Map、L0–L3、I2V、Proxy……）来保证不出错。但**给用户看的步骤、模板、计划和进度，一律用大白话**，专业名只放在括号里备注。本文件是唯一权威对照：拿不准某个词怎么跟用户说，就查这里。
>
> **三条沟通规则**
> 1. **对外白话、对内专业**：对话/交付标题用"白话名（专业名）"，首次出现给一句话解释；内部存档（Recipe、Control Map、日志）的字段键名可保留英文/专业，但交付给用户时配白话标题。
> 2. **用户说人话，AI 做翻译**：用户说"要爽/别变脸/像 3A/便宜点/你看着弄"，按 `solo-workflow.md` 0.3 的白话映射落到专业动作，不要求用户改口说术语。
> 3. **遇老手不强行翻译**：用户自己能熟练使用术语时，正常用术语、提高效率。

## 1. 整套流程在干嘛（S0–S8 白话版）

| 大白话 | 专业名 | 它到底在干嘛 |
|---|---|---|
| **第 0 步 · 先聊清楚再动手** | 开场 Intake | 你说想法，我复述一遍、列出接下来怎么做、只就关键分歧问你几个选择题 |
| **第 1 步 · 开工对齐** | S0 接案/上锁 | 确定要做什么；分清哪些**不能改**、哪些**可商量**、哪些**随便试**；判断从故事还是从素材入手 |
| **第 2 步 · 先试一条看看** | S1 风险探针 Probe | 正式开工前，挑最难的一个镜头花最小成本试拍，验证 AI 到底做不做得出来，不行就趁早换拍法 |
| **第 3 步 · 捋故事和小节拍** | S2 故事 / Beat | 把故事拆成一个个"人物或观众认知发生变化的小段" |
| **第 4 步 · 列镜头蓝图** | S3 Cut Map | 先列一张"大概要哪些镜头、什么顺序、哪些必须有"的清单，**这一步不写具体怎么拍** |
| **第 5 步 · 给单个镜头写说明书** | S4 Shot Contract + Control Map | 轮到真要做某个镜头时，才写清这镜要什么、哪些东西必须钉死 |
| **第 6 步 · 选做法、存配方** | S5 路由 + Recipe | 决定用图生还是文字生、用哪些参考图，把整套做法记成一份可复用的配方 |
| **第 7 步 · 生成 + 挑毛病** | S6 生成 + 评审循环 | 生成；能用就留、小毛病局部修、做法根本错了就换条路子 |
| **第 8 步 · 先粗剪一版** | S7 Rough Cut | 攒到一批能用的就先拼起来看，反推要补哪些、删哪些、改哪些镜头 |
| **第 9 步 · 精剪收尾交付** | S8 精剪 / QC / 交付 | 精修画面声音、过质检、写清用了什么 AI、复盘省钱经验 |

> 这些步骤**不是必须从 1 走到 9**，可以跳来跳去（比如先生成了一堆画面，再倒推故事）。

## 2. 三种"能不能改"（三类锁）

| 大白话 | 专业名 | 含义 |
|---|---|---|
| **不能改的** | Hard 硬锁 | 既定台词、结局、你明确禁止的东西、安全红线、定好的主角长相——AI 不能自作主张改，要改必须回来问你 |
| **可以商量的** | Soft 软锁 | 镜头数、时长、景别、运镜、生成顺序、用哪个模型——AI 可根据实际生成效果调整，但会记下改了什么、为什么 |
| **随便试的** | Open 开放 | 开场形式、转场、特效小细节、实验镜头——大胆试，成了用、不成就换回稳妥版 |

## 3. 你会拿到的东西（制作工件）

| 大白话 | 专业名 | 是什么 |
|---|---|---|
| **开场对齐卡** | Intake Card | 开工前的一页：我理解的片子、我的假设、要你确认的几点、接下来路线 |
| **镜头蓝图** | Cut Map | 全片镜头的粗略清单：镜号、这镜干嘛、必须/可有可无、台词怎么处理、要花几分功夫、用什么做法 |
| **镜头说明书** | Shot Contract | 单个镜头的要求：这镜的任务、开始啥样结束啥样、绝不能错的 2–3 点、怎么验收 |
| **控制点清单** | Control Map | 每镜分两栏：**必须钉死的**（错了就穿帮）和**随便 AI 发挥的**（不为它返工） |
| **花几分功夫锁画面** | Control Budget L0–L3 | 见下表，按镜头重要程度决定投入多少参考/约束，不为无关紧要的镜头浪费 |
| **镜头配方** | Generation Recipe | 这镜"怎么做成的"完整存档（参考图版本、做法、提示词、模型、试废了几条、最后用哪条），换个 AI 也能重做、发布时能说明 |
| **试拍探针** | Probe | 正式制作前的最小成本试验，一次只验证一个最担心的点，试片可丢弃 |
| **粗剪** | Rough Cut | 早早拼出的粗糙成片，用来发现缺镜、冗镜和节奏问题 |
| **翻车记录本** | Failure Log | 每条废片记一笔：什么毛病、当时怎么假设、改了啥、结果如何，沉淀成经验 |
| **角色场景图库（户口本）** | Asset Bible / 资产台账 | 角色定妆照、场景图、道具图统一登记版本，专门防止 AI 变脸、换衣服 |

**控制预算 L0–L3 白话**：
- **L0 省事档**：只写文字就能生成（过场空镜、远景）。
- **L1 加一张图**：文字 + 1 张参考图。
- **L2 多张图 + 定好开场画面**：主角戏、正脸说话用。
- **L3 全套伺候**：多张参考 + 定好开场和结尾画面 + 动作小样 + 反复局部修，只用在高潮、复杂运镜、严格衔接的镜头。
- 一个镜头如果需要的功夫超预算，说明设计不划算，回镜头蓝图改拍法。

## 4. 怎么让 AI 把画面做对（生成引擎黑话）

| 大白话 | 专业名 | 是什么 |
|---|---|---|
| **用来"钉住"画面的东西** | Control Signal 控制信号 | 参考图、开场画面、结尾画面、动作小样、音频、蒙版等；能靠它们钉死的，就别只靠文字祈祷 |
| **必须钉死的** | MUST CONTROL（高/中/低） | 错了就穿帮的要素；评"高"的必须用参考图等硬办法兜底，不能只写进提示词 |
| **随便发挥的** | CAN DRIFT | 显式列出允许 AI 自由处理、且**绝不为此重做**的部分（如背景雨滴、路人、发丝） |
| **文字直接生视频** | T2V 文生视频 | 不给图，纯靠文字从零生成，适合探索、空镜、蒙太奇 |
| **用一张图生视频（主力做法）** | I2V 图生视频 | 给一张开场图让它动起来，最能保住人物长相和场景 |
| **视频改视频** | V2V | 拿一段动作/构图近似的视频，改风格、改光线、改细节，保留运动 |
| **开场画面 / 结尾画面** | 首帧 Start Frame / 尾帧 End Frame | 规定镜头从哪一帧开始、最后必须到哪一帧，用于镜头之间接得上 |
| **动作小样** | 运动/空间代理 Motion/Spatial Proxy | 白膜、游戏简模、3D 相机路径、手机粗拍、火柴人动画、姿势序列——**只要能提供"时间+空间+动作"就能当小样**，用来锁定走位和运镜，小样本身不进成片 |
| **选哪条做法** | Generation Router 路由 | 根据"这镜最不能错什么"选生成方式：保脸→图生/多图；接动作→首尾帧；改已有视频→V2V；没参考→文字生；文字界面→纯后期 |
| **这一条能用** | Accept | 通过验收，进粗剪 |
| **小毛病局部修** | Repair | 用蒙版只修坏的那一小块，不为局部瑕疵整条重做 |
| **换条路子** | Reroute | 做法根本不对就换信号/换模型，或把复杂镜头**拆成几步做**（先稳住人物→再加运镜→最后修脸）；还不划算就回蓝图改戏 |
| **只改某一块** | Mask 蒙版 | 圈定只改人物/背景/某物体，其余不动 |
| **视频直接带配音** | 台词内嵌 | 生成视频时连说话和配音一起出来，省一次配音成本 |
| **画面声音分开做** | 声画分轨 | 先生成画面（人物按节奏演），配音另外做、后期再合，用于内嵌口型做不稳时 |

## 5. 导演和剪辑常识（听到不懵）

| 大白话 | 专业名 | 一句话 |
|---|---|---|
| 一场戏 / 一个镜头 / 一个小节拍 | Scene / Shot / Beat | 场景是一段连续剧情；镜头是成片里一次连续画面；节拍是"人物关系或观众认知发生变化的最小一段" |
| 摄影机摆哪 | 机位 / Camera Setup | 一个拍摄位置；**A 机 B 机 C 机是不同拍摄位置的代号，不是镜头序号**，一个机位可以出好几个镜头 |
| 人物在画面里多大 | 景别 | 大远景/全景/中景/近景/特写/大特写 |
| 摄影机怎么动 | 运镜 | 固定、推（靠近）、拉（远离）、跟（跟着人）、摇（原地转）、横移、环绕、手持；每次动都要有理由 |
| 动作做到一半切 | 动作切 Cut on action | 上一镜动作起手时切，下一镜接着同一个动作做，不重新起手 |
| 看向谁/什么 | 视线匹配 Eyeline match | 角色看向画外，下一镜就得是他看的那个方向的东西 |
| 拍听的人的反应 | 反应镜头 Reaction cut | 不必谁说话就一直拍谁，常切到听者脸上看台词造成的变化 |
| 声音先进 / 声音拖尾 | J-cut / L-cut | J-cut：下一场的声音提前一点进来；L-cut：上一镜的声音延续到下一镜画面 |
| 左右方向别乱跳 | 轴线 / 180° 规则 | 锁定人物的左右、朝向、运动方向，越轴会让观众分不清地理关系 |
| 兵器相接处给特写 | 接触点 / 插入镜 | 打斗关键的命中、格挡处单独给一个看得清的特写 |

## 6. 台词、口型与声音

| 大白话 | 专业名 | 一句话 |
|---|---|---|
| 这句台词要不要正脸清楚说 | 口型级 A+ / A / B / C（按镜头定） | **A+** 关键正脸长台词，多生成几条备选；**A** 普通正脸，1–2 条；**B** 用侧脸/背影/反应镜头规避正脸口型；**C** 画外音/人群嘈杂/不出声，不做口型、能用就过 |
| 连说话带配音一起生成 | 台词内嵌 | 平台支持且试拍口型可用时优先，省钱；台词前要写清语气、语速、情绪、停顿 |
| 抢话/打断/迟疑怎么标 | 标点规范 | `——` 被打断、`……` 迟疑停顿、`？` 反问、`（抢话·重叠半句）` 两人声音叠在一起 |
| 系统提示音/旁白 | 画外声 | 看不到说话者，不做口型，按 C 级处理 |

## 7. 画面质感与材质（3A / PBR 黑话）

| 大白话 | 专业名 | 一句话 |
|---|---|---|
| 让金属像金属、皮肤像皮肤 | PBR 物理材质 | 一套基于物理的写实质感规则，是"3A 游戏级真实感"的基础 |
| 光线自然弹射/缝隙暗角/反射 | GI 全局光照 / AO 环境光遮蔽 / SSR 屏幕反射 | GI 让光在环境里反弹自然；AO 让墙角、指甲缝等接触处有自然暗角；SSR 做潮湿地面、金属的反射 |
| 皮肤透光的通透感 | SSS 次表面散射 | 光打进皮肤/耳朵/玉石后透出的红润感，缺了它人脸像塑料/蜡像 |
| 背景虚化 | 景深 / 浅景深 | 主体清楚、背景虚成光斑，用于突出人物 |
| 画面横竖比例 | 画幅 | 竖屏短视频 9:16；横屏短片 16:9；电影宽银幕 2.39:1 |
| 先把长相和场景固定下来 | 定妆照 / 场景 establishing 图 | 开工前用便宜的图片工具生成角色定妆照和场景全貌图，统一景别光向，之后视频都拿它们当参考，防止变脸 |

## 8. 质检、成本与翻车

| 大白话 | 专业名 | 一句话 |
|---|---|---|
| 十类常见翻车 | 缺陷 D1–D10 | D1 变脸 / D2 多指多肢 / D3 口型台词错 / D4 运镜乱 / D5 文字乱码 / D6 动作接不上 / D7 光色跳变 / D8 一段塞太多 / D9 画面融化撕裂 / D10 人数道具穿帮 |
| 连错几条就停 | 单镜熔断 | 同一镜头同一做法**连错 3 条**就停手，按"改词→拆镜降负担→降级/换模型→改戏"换路子，不硬烧积分；关键镜最多 5–6 条 |
| 钱花得值不值 | 首轮可用率 / 平均重生次数 / 可用秒成本 | 账本算出来的三个核心指标，用来判断哪种做法省钱 |
| 哪类镜头用哪个 AI | 镜型 → 模型路由 / 回归集 | 先拿 5–6 个代表镜头试出谁擅长对白、谁擅长动作；模型升级后用同一批镜头复测，防止画风漂移 |
| 镜头首尾多留半秒 | 手柄 Handle | 每段多生成一点前后余量，方便后期剪接 |
| 同角色凑一批做 | 分批保脸 BATCH | 先做资产后做视频；同一角色/场景的镜头集中一批、复用开场图；关键正脸先做、群像只给 2–5 个前景动作、高潮最后做 |
| 交付前逐项检查 | 质检门 G0–G6 | 通用、动作、静帧、参考图、叙事对白、输出适配、AI 生成专项（G6）的检查清单 |
| 说明片子怎么用 AI 做的 | AI 披露 | 配方 + 生成日志 + 资产台账天然构成可追溯证据，投稿/发布时可导出 AI 使用说明 |

## 9. 小白版全流程（一句话串起来）

> 你把想法告诉我 → 我先**复述+列计划+问几个关键选择题**（开工对齐）→ 拿最难的镜头**先试一条**确认 AI 能做 → 用便宜的图片把**人物长相和场景定下来** → 列一张**镜头蓝图**给你确认 → 每个镜头先想清"**哪些必须钉死、哪些随便发挥、花几分功夫**"，再选**用图生还是文字生、要不要动作小样**，提示词只写氛围和表演 → **生成、能留就留、小毛病局部修、做法错了换路子**，做法都记进**配方** → 攒一批就**先粗剪**，反推补删改 → **精剪、质检、说明 AI 用法、复盘**交付。
