# 内置参考：导演工具箱（内置模块 cinematography）

# 导演工具箱（内置模块）

> 适用：C 类动作/动态视频全套。**静帧（A/B/D 单图）只读第 1 节的景别、焦距、景深、视角**，运镜、节奏、切换、声音均不适用。
> 声音、对白、音乐与静音是叙事分镜的组成部分；具体模型是否能同步生成声音、准确口型和时长需验证，无法保证时在分镜保留设计、将精确执行交给分轨配音、声音制作与剪辑。
> 本节秒数/帧数/频率默认是分镜参考，不保证视频模型逐帧服从；用户明确需要可复制时间轴或目标模型支持时间码时，精简事件时间码可以写进成品①。

## 1. 景别 / 运镜 / 镜头参数

- **景别**（单镜头主景别唯一）：大远景/航拍、全景/全身、中景、近景、特写、大特写。
- **运镜**（依空间与时间可读性选择，不设统一种数上限）：推、拉、跟拍、横移/轨道、摇、甩、升降、环绕、长镜头、手持、慢镜头、惯性跟随、动量连续跟拍、受击反馈运镜（冲击后坐→阻尼回正）。
- **焦距**：广角（夸张/环境）、标准（自然）、长焦（压缩/隔离/人像）。
- **景深**：浅景深（隔离主体、人像、情绪）、大景深（环境、史诗、空间关系）。
- **视角**：第一人称 POV、第三人称过肩、平视、低角度仰拍、高角度俯拍、 Dutch 倾斜角（失衡/危急，慎用）。

## 2. 题材 → 运镜偏好

- 打斗动作：跟拍、甩镜、低角度、中近景切换；运镜要使主角动量可读；可同向跟拍、固定镜头观察或反向迎拍，方向变化需有空间逻辑。
- 史诗场景：航拍远景、拉升镜、广角、大景深。
- 人物情绪：缓推、浅景深、长焦。
- 高速追逐：同向跟拍 + 甩镜换向，过渡段可长镜头跟随。

## 3. 受击飞行跟拍 / 击飞跟拍（四阶段）

1. **命中瞬间**：镜头沿冲击力传导方向短促后坐/震动/甩动，配命中顿帧、冲击帧、局部慢放。
2. **击飞跟拍**：镜头脱离攻击方、跟随受击者飞行轨迹，受击者保持画面主体，背景沿运动矢量方向性模糊。
3. **追击者入镜**：追击者从侧方/后方/下方高速入镜，重新建立双人关系，保持动量连续，禁止突兀闪现。
4. **再交锋/落地**：受击者翻滚/撞墙/砸地/弹起，追击到位，镜头阻尼回正。

禁止：跟飞后丢失主体、追击者无动量地突兀入镜、受击者静止悬浮。如连续更换运镜，须交代移动、切镜或过渡，保证轴线清楚。

## 4. 空中打斗 / 追逐打斗

- **空中动作词**：腾空、滞空、俯冲、空中转身、滑翔、借反冲跃起、空中甩投、近身拳脚、空中扫腿、空中肘击、翻滚、空中格挡。节奏按动作事件弹性分配，必要时在分镜参考细化到约 0.5s，禁止匀速悬浮；空中段落总量可参考不超过全片约 40%，如用户指定空战则不适用。
- **追逐动作词**：跑酷、滑翔、栈道追逐、悬索桥、屋顶飞跃、峡谷跨越、边打边追、空中追逐。追逐与打斗交替，按动作完成与空间关系切换，不强制每秒一次。

## 5. 动作分镜 vs 镜头切换（核心，二者不互相绑架）

| 维度 | 动作分镜 | 镜头切换 |
|---|---|---|
| 对象 | 角色动作、招式、打击 | 画面剪辑、镜头段落 |
| 频率 | 依据完整动作事件弹性分配；约 0.5–2s 仅作参考 | 见第 6 节时长表 |
| 目的 | 打击感、操作反馈、连招 | 视觉叙事、给观众消化 |
| 服务 | 游戏感、战斗系统 | 电影感、叙事节奏 |

**一个镜头段落内可含多个动作分镜：镜头不切，动作在切。** 一个长镜头内可容纳多个动作事件，但以动作可读性、完整接触与反馈为先；不要求凑满节拍数。

**自主判断四维度**（用户未指定时据此决定，结论在说明区标【自主判断】+理由）：

| 内容类型 | 动作分镜 | 镜头切换 |
|---|---|---|
| 游戏感连招打斗 | 动作快慢交替，约 0.5–1.5s/事件仅供规划 | 长镜头跟随，不强制切 |
| 电影感史诗战斗 | 约 1–2s/完整事件，仅供规划 | 2–4s/次 |
| 情绪铺垫/对峙 | 可延长至 2–4s/事件 | 3–6s/次 |
| 高速冲刺/追逐 | 快节拍与长位移交替，不强制均匀 | 2–3s/次 |
| 蓄力/爆发 | 按蓄势、爆发、反馈分别分配 | 一镜完成，不切 |

- 用户要「游戏感/打击感/连招/战斗系统」→ 动作分镜优先，镜头长跟随。
- 用户要「电影感/史诗/叙事/沉浸」→ 镜头切换优先，动作分镜服从镜头。
- 用户要「镜头别太碎/看不清」→ 延长镜头段落，动作在镜头内完成。
- 镜头意图：强调打击→镜头不切让人看清；强调空间关系→切换展示环境；强调情绪→延长放缓；强调速度→分镜密集 + 跟拍。
- 关键打击点优先让接触与反馈处于同一可读镜头；若用户指定切镜，应保留动作轴线和因果可读性。 过渡段（俯冲/穿越/追逐/攀升）可长镜头。

## 5A. 动作因果与时间轴粒度（C 类优先）

每条链按「起始相对站位和距离 → 预备/发力 → 攻击轨迹 → 命中或格挡/闪避 → 受力位移 → 接下一招/收势」编排。角色在空间中持续存在，起手姿势继承前一事件末态；武器、持握手、地面接触与镜头运动方向不无故重置。

时间轴以**事件边界**切分：铺垫约 1–3s，普通事件约 0.5–2s，接触点可在分镜参考中细化至约 0.1–0.5s，均属启发式而非强制参数。不要把每一秒变成互不相干的姿势清单；同一时间段可容纳相互衔接的攻击与反应，长镜头不等于慢动作。

片段接口在说明区记录：起始/结束位置、朝向、人物间距、姿态与重心、武器状态、镜头方向、地面或服饰变化。跨片段优先使用真实尾帧作为下一段图像参考；无法提供时在下一段开头显式复述末态。角色多、连招复杂或模型出现重置时先减少动作数量，再拆段。

时间码默认只进说明区；当用户要逐秒可复制版或模型确实支持时间轴，才将**简洁事件时间段**放成品区。不可承诺 0.1 秒级动作或口型必然准确。

## 6. 镜头时长参考表（建议值，不构成强制上限）

> 原则：用户明确指定的切法 > 本表 > 自动创意。不再使用「一律 2–4 秒」这类与例外冲突的绝对句。

| 段落类型 | 单镜头时长 | 切换 |
|---|---|---|
| 游戏感连招 | 3–6s 长跟随 | 少切，镜头内打满动作分镜 |
| 电影感史诗战斗 | 2–4s | 2–4s/次 |
| 情绪铺垫 / 对峙 | 3–6s | 3–6s/次 |
| 高速冲刺 / 追逐 | 2–3s | 2–3s/次 |
| 蓄力 / 爆发 / 关键打击 / 处决 | 2–5s | 不切，一镜到底 |
| 过渡（俯冲/穿越/攀升/缠斗） | 2–3s | 0–1 次，可长镜 |
| 快切连招（**仅**用户明确要「快切/MV 感/眼花缭乱」） | 1.5–2s | 1.5–2s/次 |

约束：
- 常规镜头可参考 2s 以上以保证动作可读，但快切、冲击插镜或用户指定风格可更短；由实际视频可读性决定。
- 重点/情绪段可适当延长；不设通用封顶，以模型可用时长与内容为准。
- 可用平均每约 2s 一切作为动作可读性检查起点，不是上限；按用户要求、叙事段落和实测效果调整。
- 分段生成默认每段约 3–5s，但以所选模型可用时长、用户指定与动作复杂度为准；段内尽量不切，把切换放到段与段之间。

## 7. 镜头段落规划法

1. 拆分段落：把全片拆成若干镜头段落并标注时长（参照第 6 节）。
2. 标注重点/过渡/铺垫/快切属性。
3. 根据镜头意图决定切换；重点打击优先保持接触与反馈完整，可按明确创作意图采用快切。
4. 检查关键接触与反馈是否清楚，是否有过轴或因切镜造成的动作断裂。
5. 保证每个镜头给足观众消化时间。

输出（写进说明区，不进成品）：`[镜头节奏]` 段落数 + 每段时长 + 切换次数 + 重点/过渡段；`[动作分镜]` 动作频率 + 节拍 + 打击点 + 连招；`[自主判断]` 依据 + 两类频率 + 理由。

## 8. 特写密度控制（仅 C 类视频；建议而非硬限）

先问该特写是否让观众更清楚看到接触点、人物情绪或关键装备。相邻重复特写如果没有新增信息可换成中景、反应镜或全景；如果用户要强调同一事件，可连续特写，不套用「最多三次/间隔五秒」等硬指标。

动作接触点特写可选低角度、前景近大远小、标准中景或适度广角；写实面部默认自然透视，鱼眼仅在用户明确需要且视觉意图成立时使用。不可同一镜头既要求长焦压缩又要求超广角拉伸而无变焦/换镜交代。

说明区只有在专业/剧本模式且确实有重复风险时给出特写选择理由；不要在负面提示词机械加入「同类特写重复」。

## 9. 声音 / 音效 / BGM（按题材启用的导演设计；精确执行可归后期）

- 音效分类：动作、环境、材质、情绪。与画面对齐但不固定套装：命中可选接触材质声、人物呼吸、环境余响或有意声场缺席；重低频、金属撞击和短静音只有接触材质与叙事允许时使用。蓄力/爆发/惯性也可用实时声场、错拍和休止，不必总做低频渐强+高频炸裂。
- BGM 类型：史诗管弦、低频电子、民族乐器、西部口琴/吉他、鼓点、弦乐、静音；按情绪与声场合理编配，BGM 不压音效，依剧情安排渐强与静音，不设无根据的乐器数量上限。
- 将叙事相关声音直接写入分镜「声音与节奏」栏；纯静帧不填。若需精确混音，再根据分镜导出后期声音清单，不默认重复交付。

## 10. 多角色调度

- 分级：主角、副主角、群像。同一事件保证视觉焦点清楚；焦点可按互动与叙事转移，不强制每 1–2s 切换。
- 群像规模用视觉描述；用户指定人数属于重要身份信息，可留在成品区。
- 三人以上混战可优先拆为多个关系清晰的双人镜头分别生成、后期拼接；不规定每秒动作数。

## 11. 叙事、台词、表演与声音（故事视频默认适用）

- 先判断用户提供的是**已有剧本**还是要求**原创剧本**：已有台词逐字保留，不能随意重写；梗概要求完整短片时可按人物目标与性格编写对白；明确无对白则用行为、眼神、声场叙事，不强塞台词。
- 每句关键台词包括「说话者＋原文＋对谁说／希望对方做什么＋潜台词（若有）＋声调、音量、语速、气息与停顿＋相应可观察表演」；潜台词是导演理解，不强迫角色把它说出口。台词的时长服从实际语句、演员节奏和画面目的，取消统一字数及两秒限制。
- 先判定**画内／画外／旁白／电话或设备声**，再决定镜头对准说话者还是倾听者；不强制台词期间都拍讲话的人。反应镜头、声音先行 J-cut、声音延续 L-cut、留白与静音按叙事功能启用，并就地解释声音从哪一镜开始或持续到哪一镜。
- 对白要有情绪、权力、信息或关系上的作用；沉默、呼吸、空间声同样可承担戏剧行动。表演词如「克制」「犹豫」必须落到眼神、吸气、手势、重心或说话时机，避免统一微表情模板。
- 影视声音设计须注明可听来源、主次、进入/退出和对白避让。音乐可为零；角色感情不等于一律靠煽情配乐表达。
- 目标模型若不支持音频或口型不稳定，分镜仍忠实写出台词与声音，但执行层明确可分轨配音、口型及后期剪辑；不宣称模型能精确按时间码或完成多人口型同步。
- 用户指定语言、方言或称谓时遵守；不从参考图推断真实人物身份或声线；未指定音色时只给有叙事意义的可执行特征。

**表格内推荐写法**：`年轻人：「我不是来求你的。」压低音量，先干涩后稳定；说前吸气，句末不回避目光。表面否认乞求，实际宣布不再服从。` 不另外生成重复对白时间轴，除非用户要求录音或剪辑版。
