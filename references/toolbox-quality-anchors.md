# 内置参考：质量锚点库（内置模块 quality-anchors）

# 质量锚点库（内置模块）

> 用法：按题材对标同品类顶级 3A 游戏 / 院线电影的**手法**来校准质量。只提取镜头语言、动作设计、光影、材质、节奏，**不在用户未请求时主动照搬受保护作品的角色名、剧情、标志性场景**；下文作品名仅作创作对标，不写进给用户的成品。

每类含：对标方向 · 提取维度 · 禁止与翻车点。

## 1. 写实动作 / 格斗
- **对标方向**：硬派近身格斗 3A 与写实动作片一类（拳拳到肉、无超能力）。
- **提取**：真实攻击距离、物理碰撞、受击形变与位移、关节技、手持微晃、自然光源、环境音反馈。
- **禁止**：气功波、随意飞行、匀速挥拳、命中无受力、擂台塑料布光、肢体穿过身体。

## 2. 冷兵器 / 武士剑戟
- **对标方向**：硬核武士题材 3A、剑戟片一类（居合、一击必杀、重量感）。
- **提取**：纳刀—出鞘—斩切—停顿—回鞘的节奏、刀刃窄高光、布料与尘土、命中顿帧、斩后留白、冷兵器碰撞的小量火花。
- **禁止**：魔法光剑混搭、无脑连斩无停顿、火花夸张成爆炸、刀剑无重量像塑料、铠甲镜面反光。

## 3. 赛博朋克 / 现代都市
- **对标方向**：赛博题材 3A 与霓虹都市影视一类。
- **提取**：光线追踪反射、霓虹体积光、湿地面/积水反射、全息溢色、冷暖对撞、雨夜层次、玻璃幕墙纵深、故障艺术。
- **禁止**：霓虹铺满无主次、元素堆砌、反射方向与光源矛盾、白天强开霓虹、光污染盖脸、文字招牌乱码抢主体。

## 4. 史诗奇幻 / 开放世界
- **对标方向**：开放世界奇幻 3A 与史诗片一类。
- **提取**：大气散射、多层体积雾、尺度对比（人物 vs 巨物/建筑）、上帝光束、远景空气透视、自然材质、队伍纵深。
- **禁止**：尺度无参照物、远景一片平、特效盖环境、现代物品穿帮、高饱和艳俗、巨物无重量感。

## 5. 真人写实 / COS / 人像
- **对标方向**：商业人像、影视剧照、高质量 COS 成片。
- **提取**：三层布光、85mm 浅景深、皮肤 SSS 质感、轮廓逆光、眼神光、服装做旧、自然神态与不对称。
- **禁止**：广角/鱼眼怼脸、塑料磨皮、蜡像感、过曝平光、网红滤镜、背景脏乱、强行加特效、完美对称假脸。

## 6. 动作打斗 · 受击飞行（重击专项）
- **对标方向**：强打击感动作游戏与硬派动作片的击飞段落。
- **提取**：命中顿帧、方向性镜头后坐、碎屑尘环、四阶段跟拍（命中→跟飞→追击者入镜→落地/再交锋）、追击者动量连续、阻尼回正、局部慢放。
- **禁止**：跟飞丢主体、追击者无动量闪现、受击者匀速悬浮、无落地反馈、镜头无方向乱甩、追击者与受击者速度矢量矛盾。

## 7. 追逐 / 跑酷
- **对标方向**：跑酷追逐题材游戏与长镜头追逐片。
- **提取**：动量连续跟拍、蹬墙/翻越借力、障碍破坏、背景径向模糊与速度线、边跑边打、垂直空间利用、长镜头跟随。
- **禁止**：人物原地滑步、背景不动、动作与位移脱节、跳跃无抛物线、镜头追丢主体、落地无缓冲。

## 8. 空中打斗 / 立体战斗
- **对标方向**：立体机动/空战题材 3A 一类。
- **提取**：上下方位关系、俯冲透视、翼/伞/反冲借力、0.5s 微节拍、衣摆发丝气流、落点预判、远近纵深。
- **禁止**：匀速悬浮像游泳、无重力感、方位混乱、空中无借力随意变向、空中段落过多且失去重力感、主体在远景中丢失。

## 对标提取的通用维度（任何题材都先过一遍）

镜头语言 · 动作设计 · 光影调性 · 材质标准 · 节奏把控 · 环境互动逻辑。打斗场景重点吸收：力度分层、变速爆发、撞击形变、镜头动量连续、受击反馈运镜、速度曲线（成品用视觉锚点表达，数字进参考区）。
